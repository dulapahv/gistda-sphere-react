## ฟีเจอร์ [#features]

- **ครอบคลุม Sphere API ทั้งหมด**: ทุกคลาส เหตุการณ์ และตัวเลือกของแผนที่ ดูรายละเอียดได้ที่หน้า[ความครอบคลุมของ API](/th/docs/api-coverage)
- **คอมโพเนนต์แบบ declarative** สำหรับแผนที่ หมุดและการจัดกลุ่มหมุด ป๊อปอัป รูปทรง GeoJSON ชั้นข้อมูล แท็กสถานที่ ข้อมูลสด และตัวควบคุม คืนทรัพยากรให้อัตโนมัติเมื่อเลิกใช้ และอัปเดตทันทีโดยไม่ต้องสร้างใหม่
- **ใช้ React ได้ทุกที่**: ใส่เนื้อหา React ในไอคอนหมุด ป๊อปอัป และตัวควบคุมแผนที่ได้
- **ระบบนำทางที่พร้อมใช้งานทันที**: สถานะเส้นทาง ระยะทางและเวลารวม พร้อมคำแนะนำการนำทางทีละขั้นที่อ่านเข้าใจง่ายในรูปแบบ React state
- **การค้นหา สถานที่ และ POI**: ค้นหาพร้อมคำแนะนำอัตโนมัติ สถานที่ใกล้เคียง ที่อยู่ ขอบเขตพื้นที่ และแท็กสถานที่กว่า 250 รายการใน 20 หมวดหมู่
- **ข้อมูลและการวิเคราะห์**: GeoJSON, KML, GPX และ WKT แผนที่ความร้อน การจัดกลุ่มจุด และ 3 มิติ การวัดขนาดและการดำเนินการกับรูปหลายเหลี่ยม
- **บริการเว็บ**: ไคลเอนต์ที่มี type ครบถ้วนสำหรับการนำทาง การแปลงพิกัดเป็นที่อยู่ ความสูง แผนที่ภาพนิ่ง การเกษตร ภัยพิบัติ และประชากร ใช้งานได้ทั้งในเบราว์เซอร์และบนเซิร์ฟเวอร์
- **พร้อมใช้กับ Next.js**: เรียกใช้คอมโพเนนต์จาก Server Component ได้ ส่วน hooks และ event handler อยู่ใน Client Component
- **ออกแบบมาเพื่อ TypeScript**: มี type ครบถ้วนทั้ง props, ref, ผลลัพธ์ และเหตุการณ์

## ติดตั้ง [#quick-install]

```bash
npm install gistda-sphere-react
```
