หน้านี้เทียบเคียง [เอกสารอ้างอิง Sphere API](https://api.sphere.gistda.or.th/map/doc.html) และ[บริการเว็บ](https://api.sphere.gistda.or.th/services/api)เข้ากับไลบรารีนี้ ส่วนที่ไม่ได้หุ้มไว้ยังเข้าถึงได้ผ่าน [`useMap()`](/th/docs/hooks/use-map) ซึ่งคืนค่าอ็อบเจกต์ `sphere.Map` โดยตรง

## สิ่งที่มีเพิ่มจาก Sphere API [#beyond-the-sphere-api]

ไลบรารีนี้ยังเพิ่มสิ่งที่ Sphere API ไม่มี

- คอมโพเนนต์แบบ declarative ที่คืนทรัพยากรให้อัตโนมัติเมื่อเลิกใช้ พร้อม prop ที่อัปเดตแผนที่ทันทีโดยไม่ต้องสร้างใหม่
- ใช้เนื้อหา React เป็นไอคอนหมุด ป๊อปอัป และตัวควบคุมแผนที่
- ผลลัพธ์เส้นทางเป็น React state: `status`, `summary`, `steps` สำหรับนำทางทีละขั้นที่อ่านเข้าใจง่าย และการจัดการเมื่อหมดเวลาสำหรับ key ที่ไม่ได้เปิดบริการนำทาง
- `onError` สำหรับอ็อบเจกต์ที่โหลดไม่สำเร็จ และข้อผิดพลาดพร้อมรหัสสำหรับบริการเว็บทุกตัว
- การวิเคราะห์เชิงพื้นที่และการวัดขนาดบน ref ของรูปทรงทุกชนิด
- ไคลเอนต์บริการเว็บที่มี type ครบ และใช้บนเซิร์ฟเวอร์ได้ด้วย
- จัดการข้อจำกัดของ Sphere ให้อัตโนมัติ: `input={false}` เพื่อปิดการโต้ตอบ, ป้ายชื่อในโหมด Fly, การลบแท็กแบบ `"a|b"`, ค่าพื้นที่แบบข้อความธรรมดา และอื่น ๆ
