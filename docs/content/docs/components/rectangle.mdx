```tsx
<Rectangle
  position={{ lon: 100.45, lat: 13.8 }}
  size={{ width: 0.1, height: 0.1 }}
  fillColor="rgba(0, 200, 0, 0.3)"
  lineColor="green"
/>
```

## Props

| Prop | Type | Description |
| --- | --- | --- |
| `position` | `Location` | **Required.** Top-left corner. |
| `size` | `Size \| Location` | **Required.** `{ width, height }` in degrees, or the bottom-right corner. |

Rectangles also take the [shape props](/docs/components/polygon#shape-props), including `editable`.

```tsx
// Both describe the same box:
<Rectangle position={{ lon: 100.45, lat: 13.8 }} size={{ width: 0.1, height: 0.1 }} />
<Rectangle position={{ lon: 100.45, lat: 13.8 }} size={{ lon: 100.55, lat: 13.7 }} />
```

## Ref

Rectangles have the same ref methods as [polygons](/docs/components/polygon#ref), including `getArea`, `union`, `intersection`, `difference` and `split`, plus `getRectangle()` for the underlying `sphere.Rectangle`.
