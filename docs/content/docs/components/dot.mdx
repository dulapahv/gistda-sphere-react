```tsx
<Dot
  position={{ lon: 100.5018, lat: 13.7563 }}
  lineColor="red"
  lineWidth={12}
/>
```

Unlike a [`Circle`](/docs/components/circle), whose radius is a distance on the ground, a dot keeps the same size on screen at every zoom level. `lineWidth` sets its diameter in pixels.

## Props

| Prop | Type | Description |
| --- | --- | --- |
| `position` | `Location` | **Required.** Where the dot is. Changing it moves the dot without re-creating it. |
| `onDrop` | `(dot, location) => void` | A draggable dot was dropped at `location`. |

Dots also take the [shape props](/docs/components/polygon#shape-props), such as `lineColor`, `lineWidth`, `draggable` and `title`.
