---

`SphereMap` สร้างแผนที่ Sphere ภายใน `<div>` และแสดงคอมโพเนนต์ลูก (หมุด รูปทรง เลเยอร์ ตัวควบคุม…) เมื่อแผนที่พร้อมใช้งาน

<SphereMapDemo />

```tsx
<SphereMap
  center={{ lon: 100.5018, lat: 13.7563 }}
  zoom={10}
  language="en"
  style={{ height: 400 }}
  onClick={({ lat, lon }) => console.log(`Clicked at ${lat}, ${lon}`)}
>
  <Marker position={{ lon: 100.5018, lat: 13.7563 }} title="Bangkok" />
</SphereMap>
```

<Callout>
  แผนที่จะขยายเต็มพื้นที่ของคอนเทนเนอร์ จึงต้องกำหนดความสูงให้แผนที่ (หรือคอนเทนเนอร์) หากไม่กำหนด `<div>` จะสูง 0 px
</Callout>

## Props

props ที่ระบุว่า **อัปเดตทันที** จะอัปเดตแผนที่เมื่อค่าเปลี่ยนโดยไม่ต้องสร้างใหม่ ส่วน props อื่นใช้กำหนดสถานะเริ่มต้นเท่านั้น หากต้องการเปลี่ยนภายหลัง ให้ใช้ [ref](#ref) หรือ [`useMapControls`](/th/docs/hooks/use-map-controls)

| Prop | ชนิด | ค่าเริ่มต้น | คำอธิบาย |
| --- | --- | --- | --- |
| `center` | `Location` | ค่าเริ่มต้นของ Sphere | จุดกึ่งกลางเริ่มต้น `{ lon, lat }` |
| `zoom` | `number` | `7` | ระดับซูมเริ่มต้น (0–22) |
| `rotate` | `number` | `0` | มุมหมุนเริ่มต้นเป็นองศา ตามเข็มนาฬิกาจากทิศเหนือ |
| `pitch` | `number` | `0` | มุมเอียงเริ่มต้นเป็นองศา (สูงสุด 60 โดยค่าเริ่มต้น) |
| `language` | `"th" \| "en"` | `"th"` | **อัปเดตทันที** ภาษาของป้ายชื่อและ UI ในตัว |
| `baseLayer` | `LayerInput` | `"STREETS"` | **อัปเดตทันที** แผนที่ฐาน: ชื่อเลเยอร์ในตัว, `sphere.Layer`, URL ของสไตล์ MapLibre หรืออ็อบเจ็กต์สไตล์ |
| `filter` | `FilterType` | `"None"` | **อัปเดตทันที** ตัวกรองสี: `"None"`, `"Dark"`, `"Light"`, `"Protanopia"` หรือ `"Deuteranopia"` |
| `zoomRange` | `Range` | `{ min: 0, max: 22 }` | **อัปเดตทันที** ช่วงระดับซูมที่ผู้ใช้ซูมได้ `{ min, max }` |
| `controls` | `UiControlsConfig` | – | **อัปเดตทันที** แสดงหรือซ่อนตัวควบคุมในตัว เช่น `{ DPad: false, Scale: true }` |
| `ui` | `"Full" \| "Mobile" \| "None"` | ตามขนาดคอนเทนเนอร์ | รูปแบบ UI ในตัวที่จะสร้าง ดู[รูปแบบ UI](#ui-modes) |
| `input` | `boolean` | `true` | อนุญาตให้ผู้ใช้ควบคุมด้วยเมาส์ การสัมผัส และคีย์บอร์ด |
| `lastView` | `boolean` | `false` | กู้คืนจุดกึ่งกลางและระดับซูมล่าสุดจาก local storage |
| `options` | `Record<string, unknown>` | – | ตัวเลือกเพิ่มเติมสำหรับ `new sphere.Map()` รวมถึง[ตัวเลือกแผนที่ของ MapLibre](https://maplibre.org/maplibre-gl-js/docs/API/type-aliases/MapOptions/)ทุกตัว |
| `ref` | `Ref<SphereMapRef>` | – | ควบคุมแบบ imperative ดู [Ref](#ref) |
| `style`, `className`, `id` | – | – | กำหนดให้กับ `<div>` คอนเทนเนอร์ |
| `children` | `ReactNode` | – | แสดงเมื่อแผนที่พร้อมใช้งาน |

## เหตุการณ์ [#events]

ทุกเหตุการณ์ของแผนที่ Sphere มี callback prop ของตัวเอง โดยแต่ละ handler จะได้รับค่าที่ Sphere ส่งมา

| Prop | อาร์กิวเมนต์ | เกิดเมื่อ |
| --- | --- | --- |
| `onReady` | `(map)` | แผนที่พร้อมใช้งาน คอมโพเนนต์ลูกเริ่มแสดงผลตั้งแต่จุดนี้ |
| `onClick` | `({ lat, lon, x, y })` | คลิกแผนที่ (ไม่เกิดเมื่อคลิกโอเวอร์เลย์) |
| `onDoubleClick` | `({ lat, lon, x, y })` | ดับเบิลคลิกแผนที่ |
| `onMouseMove` | `({ lat, lon, x, y })` | เลื่อนเมาส์บนแผนที่ |
| `onWheel` | `({ x, y, delta })` | หมุนล้อเมาส์ |
| `onZoom` | `(zoom)` | ระดับซูมเปลี่ยน |
| `onLocation` | `(center)` | จุดกึ่งกลางเปลี่ยน |
| `onRotate` | `(angle)` | มุมหมุนเปลี่ยน |
| `onPitch` | `(angle)` | มุมเอียงเปลี่ยน |
| `onZoomRange` | `({ min, max })` | ช่วงซูมที่อนุญาตเปลี่ยน |
| `onDrag` / `onDrop` | `()` | ผู้ใช้เริ่ม / หยุดลากแผนที่ |
| `onIdle` | `()` | แผนที่แสดงผลเสร็จ |
| `onRepaint` | `()` | แผนที่ถูกวาดใหม่ |
| `onResize` | `()` | แผนที่เปลี่ยนขนาด |
| `onFullscreen` | `(isFullscreen)` | เปิดหรือปิดโหมดเต็มจอ |
| `onLayerChange` | `(added)` หรือ `(undefined, removed)` | เพิ่มหรือลบเลเยอร์ |
| `onTileLoading` / `onTileLoaded` | `(sourceId)` | ไทล์ของ source เริ่ม / โหลดเสร็จ |
| `onOverlayClick` | `(overlay, location)` | คลิกโอเวอร์เลย์ |
| `onOverlayHover` / `onOverlayLeave` | `(overlay)` | เมาส์เข้า / ออกจากโอเวอร์เลย์ |
| `onOverlayDrag` / `onOverlayDrop` | `(overlay)` | กำลังลาก / วางโอเวอร์เลย์ |
| `onOverlayChange` | `(overlay)` | เพิ่มหรือลบโอเวอร์เลย์ |
| `onOverlayUpdate` | `(overlay)` | แก้ไขโอเวอร์เลย์ |
| `onOverlayLoad` | `(data)` | [โอเวอร์เลย์สำเร็จรูป](/th/docs/components/predefined-overlay)หรือ[อ็อบเจ็กต์](/th/docs/components/object-overlay)โหลดเสร็จ |
| `onPopupClose` | `(popup)` | ปิดป๊อปอัป |
| `onBeforeContextMenu` | `({ location, add })` | เมนูคลิกขวากำลังจะเปิด เรียก `add(element)` เพื่อเพิ่มรายการ หรือคืนค่า `false` เพื่อยกเลิก |
| `onContextMenu` | `()` | เมนูคลิกขวาเปิดแล้ว |
| `onRouteComplete` | `(routes)` | คำนวณเส้นทางเสร็จ แนะนำให้ใช้ [`useRoute`](/th/docs/hooks/use-route) |
| `onRouteError` | `(status)` | คำนวณเส้นทางไม่สำเร็จ |
| `onToolbarChange` | `(mode)` | แถบเครื่องมือวาดเปลี่ยนโหมด |
| `onDrawCreate` / `onDrawDelete` | `(features)` | วาด / ลบรูปทรงด้วยแถบเครื่องมือในตัว |
| `onTooltipChange` | `(message)` | ข้อความ tooltip ของแถบเครื่องมือเปลี่ยน |
| `onError` | `(error: Error)` | แผนที่รายงานข้อผิดพลาด |

หากต้องการรับเหตุการณ์จากคอมโพเนนต์ลูก ให้ใช้ [`useMapEvent`](/th/docs/hooks/event-hooks)

## แผนที่ฐานและตัวกรองสี [#base-maps-and-filters]

```tsx
const [dark, setDark] = useState(false);

<SphereMap baseLayer="HYBRID" filter={dark ? "Dark" : "None"} />
```

แผนที่ฐานในตัว ได้แก่ `"SIMPLE"`, `"STREETS"`, `"STREETS_NIGHT"`, `"HYBRID"` และ `"IMAGES"` และ `baseLayer` ยังรับสไตล์ MapLibre ได้ด้วย เช่น สไตล์เวกเตอร์ของ Sphere

```tsx
<SphereMap baseLayer="https://basemap.sphere.gistda.or.th/vector/sphere_hybrid.json" />
```

## ตัวควบคุมในตัว [#built-in-controls]

```tsx
<SphereMap controls={{ DPad: false, Zoombar: true, Scale: true, LayerSelector: false }} />
```

| ตัวควบคุม | คำอธิบาย |
| --- | --- |
| `DPad` | ปุ่มลูกศรสำหรับเลื่อนแผนที่ |
| `Zoombar` | ปุ่มซูมเข้า/ออก |
| `Geolocation` | ไปยังตำแหน่งของผู้ใช้ |
| `Toolbar` | เครื่องมือวาดและวัดระยะ (เฉพาะ UI แบบเดสก์ท็อป) |
| `LayerSelector` | เมนูแผนที่ฐานและชั้นข้อมูล |
| `Fullscreen` | ปุ่มเต็มจอ (เฉพาะ UI แบบเดสก์ท็อป) |
| `Crosshair` | เป้าตรงกลางแผนที่ |
| `Scale` | มาตราส่วน |
| `ContextMenu` | เมนูคลิกขวา |

สำหรับการตั้งค่าการควบคุม การล็อกแผนที่ และเมนูคลิกขวา ดู [`useUi`](/th/docs/hooks/use-ui) และหากต้องการเพิ่มตัวควบคุมของคุณเอง ดู [`MapControl`](/th/docs/components/map-control) และ [`MenuBar`](/th/docs/components/menu-bar)

## รูปแบบ UI [#ui-modes]

| `ui` | คำอธิบาย |
| --- | --- |
| `"Full"` | ตัวควบคุมแบบเดสก์ท็อป: แถบซูม ปุ่มทิศทาง ตำแหน่งของฉัน แถบเครื่องมือ เมนูชั้นข้อมูล เต็มจอ และมาตราส่วน |
| `"Mobile"` | ตัวควบคุมแบบกะทัดรัดสำหรับจอขนาดเล็ก (ไม่มีแถบเครื่องมือ) |
| `"None"` | ไม่มี UI ในตัว |

หากไม่กำหนด `ui` Sphere จะใช้ UI แบบมือถือเมื่อแผนที่กว้างน้อยกว่า 600 px

## ตัวเลือกของ MapLibre [#maplibre-options]

`options` จะถูกส่งให้ `new sphere.Map()` และ Sphere จะส่งต่อให้ MapLibre ใช้กับทุกอย่างที่ MapLibre รองรับได้

```tsx
<SphereMap
  options={{
    maxPitch: 85,         // allow steeper tilts
    hash: true,           // keep the view in the URL
    doubleClickZoom: false,
  }}
/>
```

## Ref

ref มีเมธอดทั้งหมดของ [`useMapControls`](/th/docs/hooks/use-map-controls) และ `getMap()`

```tsx
const mapRef = useRef<SphereMapRef>(null);

<SphereMap ref={mapRef} />

mapRef.current?.goTo({ center: { lon: 98.98, lat: 18.79 }, zoom: 12 });
mapRef.current?.setRotate(45);
const sphereMap = mapRef.current?.getMap(); // the sphere.Map instance
const maplibre = sphereMap?.Renderer;        // the MapLibre map
```

| เมธอด | คำอธิบาย |
| --- | --- |
| `getMap()` | `sphere.Map` ที่อยู่เบื้องหลัง หรือ `null` โดย `Renderer` คือแผนที่ MapLibre |
| `goTo(options, animate?)` | เคลื่อนไปยังมุมมองที่กำหนด (`center`, `zoom`, `bearing`, `pitch`, `padding`, `duration`) |
| `setCenter` / `getCenter` | จุดกึ่งกลางของแผนที่ |
| `setZoom` / `getZoom`, `zoomIn`, `zoomOut` | ระดับซูม |
| `setRotate` / `getRotate` | มุมหมุนเป็นองศา |
| `setPitch` / `getPitch` | มุมเอียงเป็นองศา |
| `setBound(bound, options?)` / `getBound` | ปรับมุมมองให้พอดีกับขอบเขต หรืออ่านขอบเขตที่มองเห็น |
| `panBy({ x, y })` | เลื่อนแผนที่ตามจำนวนพิกเซล |
| `setZoomRange` / `getZoomRange` | ช่วงระดับซูมที่อนุญาต |
| `setBaseLayer`, `addLayer`, `removeLayer`, `clearLayers`, `getLayers` | จัดการเลเยอร์ |
| `setFilter` / `getFilter` | ตัวกรองสี |
| `setLanguage` / `getLanguage` | ภาษาของแผนที่ |
| `loadPredefinedOverlay` / `unloadPredefinedOverlay` | ข้อมูลสด (กล้อง เหตุการณ์ คุณภาพอากาศ) |
| `repaint`, `resize` | วาดใหม่ หรือวัดขนาดใหม่หลังคอนเทนเนอร์เปลี่ยนขนาด |

<Callout type="warn">
  การเปลี่ยน props `center`, `zoom`, `rotate` หรือ `pitch` หลังการแสดงผลครั้งแรกจะไม่มีผล ให้เลื่อนแผนที่ด้วย ref หรือ `useMapControls` เพื่อไม่ให้การ re-render ไปทับตำแหน่งที่ผู้ใช้เลื่อนไว้
</Callout>
