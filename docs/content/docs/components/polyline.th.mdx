```tsx
import { Polyline, SphereMap } from "gistda-sphere-react";

<SphereMap center={{ lon: 100.55, lat: 13.75 }} style={{ height: 400 }} zoom={10}>
  <Polyline
    positions={[
      { lon: 100.4, lat: 13.7 },
      { lon: 100.5, lat: 13.8 },
      { lon: 100.6, lat: 13.7 },
      { lon: 100.7, lat: 13.8 },
    ]}
    lineColor="blue"
    lineWidth={4}
    lineStyle="Dashed"
    title="Route A"
  />
</SphereMap>
```

ตัวอย่างสั้น ๆ ด้านล่างละ `<SphereMap>` ไว้ แต่โอเวอร์เลย์ทุกตัวต้องอยู่ภายใน `<SphereMap>` เสมอ

## Props

| Prop | ชนิด | คำอธิบาย |
| --- | --- | --- |
| `positions` | `Location[] \| GeoJSON` | **จำเป็น** จุดตามแนวเส้น (อย่างน้อย 2 จุด) ค่า `null` จะแบ่งเป็นหลายเส้น หรือใช้ GeoJSON `LineString` / `MultiLineString` ก็ได้ |

เส้นรับ [props ของรูปทรง](/th/docs/components/polygon#shape-props) ด้วย เช่น `lineColor`, `lineWidth`, `lineStyle`, `label`, `popupContent` และ event callbacks

## รูปแบบเส้น [#line-styles]

`lineStyle` รับค่า `"Solid"`, `"Dashed"`, `"Dot"` หรือรูปแบบเส้นประที่กำหนดเอง

```tsx
import { Polyline } from "gistda-sphere-react";

<Polyline positions={path} lineStyle={[12, 4, 2, 4]} lineWidth={3} />
```

## Ref

| เมธอด | คำอธิบาย |
| --- | --- |
| `getPolyline()` | `sphere.Polyline` ที่อยู่เบื้องหลัง |
| `getLength(language?)` | ความยาวเป็นเมตร หรือข้อความ เช่น `"15.5 กม."` เมื่อระบุภาษา |
| `union(other)` | เส้นใหม่ที่รวมเส้นนี้กับอีกเส้น (ไม่ถูกเพิ่มลงแผนที่) |
| `getBound()`, `getCentroid()`, `getPivot()` | ขอบเขต จุดศูนย์กลาง และจุดวางป้ายชื่อ |
| `contains`, `intersects`, `within`, `distanceTo` | การทดสอบเชิงพื้นที่ ดู[การวิเคราะห์เชิงพื้นที่](/th/docs/examples/spatial-analysis) |
| `rotate`, `shift`, `updateStyle`, `togglePopup`, `toGeoJSON` | เหมือนกับ[รูปหลายเหลี่ยม](/th/docs/components/polygon#ref) |
