`SphereProvider` โหลดสคริปต์ GISTDA Sphere เพียงครั้งเดียวต่อหน้า แล้วส่งต่อให้ทุกอย่างที่อยู่ภายในใช้งาน ควรวางไว้ใกล้ราก (root) ของแอป เหนือ `SphereMap` ทุกตัวและทุกคอมโพเนนต์ที่ใช้ hooks

```tsx
"use client";

import { SphereMap, SphereProvider } from "gistda-sphere-react";

export function App() {
  return (
    <SphereProvider apiKey={process.env.NEXT_PUBLIC_SPHERE_API_KEY!}>
      <SphereMap style={{ height: 400 }} />
    </SphereProvider>
  );
}
```

## Props

| Prop | ชนิด | ค่าเริ่มต้น | คำอธิบาย |
| --- | --- | --- | --- |
| `apiKey` | `string` | **จำเป็น** | API key ของ Sphere ดู[การขอ API Key](/th/docs/getting-started/api-key) |
| `children` | `ReactNode` | **จำเป็น** | แอปของคุณ |
| `language` | `"th" \| "en"` | – | ภาษาเริ่มต้นของทุกแผนที่ที่อยู่ภายใน รวมถึง [`useSphereServices`](/th/docs/hooks/use-sphere-services) และชื่อหมวดหมู่ของ [`useTagCategories`](/th/docs/hooks/use-tag-categories) แผนที่ที่ไม่ได้กำหนด `language` เองจะใช้ค่านี้ หากไม่กำหนดจะแสดงภาษาไทย ดู[ภาษา](#language) |
| `onLoad` | `() => void` | – | เรียกเมื่อโหลดสคริปต์ Sphere เสร็จ |
| `onError` | `(error: Error) => void` | – | เรียกเมื่อโหลดสคริปต์ไม่สำเร็จ เช่น key ไม่ได้อนุญาตให้ใช้กับโดเมนนี้ |
| `scriptUrl` | `string` | `https://api.sphere.gistda.or.th/map/?key=…` | โหลดสคริปต์จาก URL อื่น เช่น proxy |
| `formatPoi` | `(poi: PoiResult, language: string) => HTMLElement` | – | สร้างเนื้อหาป๊อปอัปที่ Sphere แสดงสำหรับแท็ก POI และผลการค้นหา |
| `poiPopupOptions` | `(source, id, name, language) => PopupOptions` | – | แทนที่ป๊อปอัป POI ทั้งหมด มีลำดับความสำคัญเหนือ `formatPoi` |

## สถานะการโหลด [#loading-state]

สคริปต์โหลดแบบ asynchronous โดย hooks จะรายงาน `isReady` และ `useSphere()` ให้สถานะการโหลดโดยตรง

```tsx
import { useSphere } from "gistda-sphere-react";

function Status() {
  const { isLoaded, error } = useSphere();
  if (error) return <p>Couldn't load the map: {error.message}</p>;
  return isLoaded ? null : <p>Loading map…</p>;
}
```

## ภาษา [#language]

แผนที่จะแสดงป้ายชื่อเป็นภาษาไทยโดยค่าเริ่มต้น กำหนด `language` ที่ provider เพียงครั้งเดียวเพื่อเปลี่ยนภาษาของทุกแผนที่ รวมถึงผลการค้นหา คำแนะนำการนำทาง และผลลัพธ์จากบริการเว็บ:

```tsx
import { SphereMap, SphereProvider } from "gistda-sphere-react";

<SphereProvider apiKey={apiKey} language="en">
  <SphereMap style={{ height: 400 }} />
</SphereProvider>
```

`language` ที่กำหนดบนแผนที่แต่ละแผนที่จะมีผลเหนือค่าของ provider

## ปรับแต่งป๊อปอัปของ POI [#customizing-poi-popups]

เมื่อผู้ใช้คลิก POI จาก [`<Tag>`](/th/docs/components/tag) หรือผลการค้นหา Sphere จะแสดงป๊อปอัปรายละเอียดของสถานที่ ใช้ `formatPoi` เพื่อแสดงเนื้อหาของคุณเอง

```tsx
import { SphereProvider } from "gistda-sphere-react";

<SphereProvider
  apiKey={apiKey}
  formatPoi={(poi) => {
    const element = document.createElement("div");
    const name = document.createElement("strong");
    name.textContent = poi.name;
    const address = document.createElement("p");
    address.textContent = poi.address ?? "";
    element.append(name, address);
    return element;
  }}
>
```

<Callout type="warn">
  ให้แทรกข้อมูลสถานที่ด้วย `textContent` ตามตัวอย่างด้านบน หากสร้าง HTML ด้วย `innerHTML` แทน ต้อง escape ทุกค่าก่อน
</Callout>

หากต้องการควบคุมป๊อปอัปทั้งหมด เช่น โหลดรายละเอียดจากบริการของคุณเอง ให้คืนค่า popup options จาก `poiPopupOptions`

```tsx
import { SphereProvider } from "gistda-sphere-react";

<SphereProvider
  apiKey={apiKey}
  poiPopupOptions={(source, id, name) => ({
    title: name,
    loadDetail: async (element) => {
      const details = await fetch(`/api/places/${id}`).then((r) => r.json());
      element.textContent = details.summary;
    },
  })}
>
```

ทั้งสองฟังก์ชันจะถูกติดตั้งบน `sphere.Util` ขณะที่ provider ทำงานอยู่ และคืนค่าเดิมเมื่อ provider ถูก unmount

## การใช้งานกับ Next.js [#using-it-with-nextjs]

คอมโพเนนต์ทุกตัวในไลบรารีนี้เป็น Client Component จึงเรียกใช้ `SphereProvider` และ `SphereMap` จาก Server Component ได้ด้วย เช่น ใน root layout:

```tsx title="app/layout.tsx"
import { SphereProvider } from "gistda-sphere-react";
import type { ReactNode } from "react";

export default function RootLayout({ children }: { children: ReactNode }) {
  return (
    <html lang="en">
      <body>
        <SphereProvider
          apiKey={process.env.NEXT_PUBLIC_SPHERE_API_KEY!}
          language="en"
        >
          {children}
        </SphereProvider>
      </body>
    </html>
  );
}
```

Server Component ส่งฟังก์ชันเป็น props และเรียกใช้ hooks ไม่ได้ ดังนั้นให้วาง event handler เช่น `onClick` ฟังก์ชัน callback เช่น `formatPoi` และ hooks ไว้ใน Client Component (ไฟล์ที่ขึ้นต้นด้วย `"use client"`) ส่วน[ไคลเอนต์บริการเว็บ](/th/docs/web-services#on-a-server)ใช้งานบนเซิร์ฟเวอร์ได้เช่นกัน

## แผนที่เดียวหรือหลายแผนที่ [#one-map-or-several]

provider หนึ่งตัวรองรับแผนที่ได้หลายแผนที่ คอมโพเนนต์และ hooks ที่อยู่**ภายใน** `SphereMap` จะทำงานกับแผนที่นั้นเสมอ ส่วน hooks ที่อยู่**ภายนอก**แผนที่ เช่น ในแถบด้านข้าง จะทำงานกับแผนที่ปัจจุบันของ provider ซึ่งคือแผนที่ที่พร้อมใช้งานล่าสุด หากต้องการให้ hooks ในแถบด้านข้างทำงานกับหลายแผนที่พร้อมกัน ให้ใช้ `SphereProvider` แยกสำหรับแต่ละแผนที่
