import { Rectangle, SphereMap } from "gistda-sphere-react";

ตัวอย่างสั้น ๆ ด้านล่างละ `<SphereMap>` ไว้ แต่โอเวอร์เลย์ทุกตัวต้องอยู่ภายใน `<SphereMap>` เสมอ

## Props

| Prop | ชนิด | คำอธิบาย |
| --- | --- | --- |
| `position` | `Location` | **จำเป็น** มุมบนซ้าย |
| `size` | `Size \| Location` | **จำเป็น** `{ width, height }` เป็นองศา หรือมุมล่างขวา |

สี่เหลี่ยมรับ [props ของรูปทรง](/th/docs/components/polygon#shape-props) ด้วย รวมถึง `editable`

```tsx
import { Rectangle } from "gistda-sphere-react";

// Both describe the same box:
<Rectangle position={{ lon: 100.45, lat: 13.8 }} size={{ width: 0.1, height: 0.1 }} />
<Rectangle position={{ lon: 100.45, lat: 13.8 }} size={{ lon: 100.55, lat: 13.7 }} />
```

## Ref

สี่เหลี่ยมมีเมธอดของ ref เหมือนกับ[รูปหลายเหลี่ยม](/th/docs/components/polygon#ref) รวมถึง `getArea`, `union`, `intersection`, `difference` และ `split` และมี `getRectangle()` สำหรับ `sphere.Rectangle` ที่อยู่เบื้องหลัง
