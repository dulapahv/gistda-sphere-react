  />

## Props

| Prop | ชนิด | คำอธิบาย |
| --- | --- | --- |
| `center` | `Location` | **จำเป็น** จุดศูนย์กลางของวงกลม |
| `radius` | `number` | **จำเป็น** รัศมีเป็นองศา 1 องศาประมาณ 111 กม. ดังนั้น `0.01` ประมาณ 1.1 กม. |

วงกลมรับ [props ของรูปทรง](/th/docs/components/polygon#shape-props) ด้วย

<Callout>
  หากต้องการกำหนดรัศมีเป็นเมตร ให้หารด้วยความยาวของ 1 องศา: `radius={meters / 111_320}`
</Callout>

## Ref
