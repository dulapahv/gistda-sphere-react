```tsx
<Popup
  position={{ lon: 100.5018, lat: 13.7563 }}
  title="Bangkok"
  detail="Capital of Thailand"
  onClose={() => setOpen(false)}
/>
```

`<Popup>` จะเปิดอยู่ตราบที่ถูกแสดงผล ให้แสดงแบบมีเงื่อนไขและนำออกใน `onClose` สำหรับป๊อปอัปที่เปิดเมื่อคลิกหมุดหรือรูปทรง ให้ใช้ props `detail`, `popup` หรือ `popupContent` ของคอมโพเนนต์นั้นแทน

## Props

| Prop | ชนิด | ค่าเริ่มต้น | คำอธิบาย |
| --- | --- | --- | --- |
| `position` | `Location` | **จำเป็น** | ตำแหน่งที่ป๊อปอัปชี้ เมื่อเปลี่ยนค่า ป๊อปอัปจะย้ายโดยไม่ต้องสร้างใหม่ |
| `title` | `string` | – | ข้อความหัวเรื่อง |
| `detail` | `string` | – | ข้อความหรือ HTML ในเนื้อหา |
| `children` | `ReactNode` | – | เนื้อหา React ที่แสดงใต้หัวเรื่อง |
| `html` | `string` | – | HTML แบบกำหนดเองทั้งหมด แทนที่โครงสร้างหัวเรื่องและเนื้อหา |
| `loadDetail` | `(element) => void` | – | เติมเนื้อหาเองเมื่อป๊อปอัปเปิด |
| `loadHtml` | `(element) => void` | – | เติมป๊อปอัปทั้งหมดเองทุกครั้งที่เปิด |
| `size` | `Size` | – | ขนาดคงที่ `{ width, height }` |
| `closable` | `boolean` | `true` | แสดงปุ่มปิด |
| `options` | `Record<string, unknown>` | – | ตัวเลือกเพิ่มเติมสำหรับ `new sphere.Popup()` รวมถึง[ตัวเลือกป๊อปอัปของ MapLibre](https://maplibre.org/maplibre-gl-js/docs/API/type-aliases/PopupOptions/) เช่น `anchor`, `offset`, `className` หรือ `closeOnClick` |
| `onClose` | `(popup) => void` | – | ผู้ใช้ปิดป๊อปอัป |
| `ref` | `Ref<PopupRef>` | – | ดู [Ref](#ref) |

## เนื้อหาแบบ React [#react-content]

```tsx
{selected && (
  <Popup
    position={selected.location}
    title={selected.name}
    onClose={() => setSelected(null)}
  >
    <img src={selected.photo} alt="" width={200} />
    <button onClick={() => book(selected.id)}>Book a table</button>
  </Popup>
)}
```

## แสดงป๊อปอัปตรงจุดที่ผู้ใช้คลิก [#show-a-popup-where-the-user-clicks]

```tsx
const [clicked, setClicked] = useState<Location | null>(null);

<SphereMap onClick={({ lat, lon }) => setClicked({ lat, lon })}>
  {clicked && (
    <Popup
      position={clicked}
      title="Coordinates"
      detail={`${clicked.lat.toFixed(5)}, ${clicked.lon.toFixed(5)}`}
      onClose={() => setClicked(null)}
    />
  )}
</SphereMap>
```

## Ref

| เมธอด | คำอธิบาย |
| --- | --- |
| `getPopup()` | `sphere.Popup` ที่อยู่เบื้องหลัง |
| `getElement()` | DOM element ของป๊อปอัป |
| `getPosition()` / `setPosition(location)` | อ่านหรือย้ายตำแหน่งป๊อปอัป |
| `setTitle(text)` / `setDetail(text)` | เปลี่ยนข้อความโดยไม่ต้องสร้างป๊อปอัปใหม่ |
