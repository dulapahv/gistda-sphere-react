`<ObjectOverlay>` โหลดอ็อบเจ็กต์สำเร็จรูปจาก Sphere เช่น เขตการปกครองหรือสถานที่ แล้ววาดบนแผนที่: พื้นที่เป็นรูปหลายเหลี่ยม และจุดเป็นหมุด รหัสได้มาจาก[ผลการค้นหา](/th/docs/hooks/use-search) (ค่า `id` ของแต่ละผลลัพธ์)

<ObjectOverlayDemo />

```tsx
<ObjectOverlay
  id="A10000000"               // Bangkok
  fitBounds
  fillColor="rgba(59, 130, 246, 0.15)"
  lineColor="rgb(37, 99, 235)"
  label
  onLoad={(data, overlays) => console.log("Loaded", data)}
  onError={(error) => setMessage(error.message)}
/>
```

<Callout type="warn">
  อ็อบเจ็กต์มาจากบริการรายละเอียดสถานที่ (`poi/get`) ของ Sphere หาก API key ไม่ได้เปิดบริการนี้ Sphere จะไม่วาดอะไรและไม่แจ้งข้อผิดพลาด ใช้ `onError` เพื่อตรวจจับ ซึ่งจะถูกเรียกเมื่ออ็อบเจ็กต์โหลดไม่เสร็จภายใน `timeout`
</Callout>

## Props

| Prop | ชนิด | ค่าเริ่มต้น | คำอธิบาย |
| --- | --- | --- | --- |
| `id` | `string` | **จำเป็น** | รหัสอ็อบเจ็กต์ เช่น `"A10000000"` (กรุงเทพฯ) หรือรหัส POI เช่น `"P00000046"` |
| `dataset` | `string` | ค่าเริ่มต้นของ Sphere | ชุดข้อมูลที่จะโหลดอ็อบเจ็กต์ |
| `fitBounds` | `boolean \| FitBoundsOptions` | – | ปรับมุมมองให้พอดีกับอ็อบเจ็กต์เมื่อโหลดเสร็จ |
| `label` | `string \| boolean` | – | ข้อความป้ายชื่อ หรือ `true` เพื่อใช้ชื่อของอ็อบเจ็กต์ |
| `icon` | `Icon` | – | ไอคอนหมุดสำหรับอ็อบเจ็กต์แบบจุด |
| `onLoad` | `(data, overlays) => void` | – | อ็อบเจ็กต์โหลดเสร็จ `overlays` คือรูปทรงที่สร้างขึ้น |
| `onError` | `(error) => void` | – | อ็อบเจ็กต์โหลดไม่เสร็จภายใน `timeout` |
| `timeout` | `number` | `15000` | เวลารอ (มิลลิวินาที) ก่อนเรียก `onError` ส่ง `0` เพื่อปิด |
| `onClick` | `(overlay, location) => void` | – | คลิกรูปทรงของอ็อบเจ็กต์ |
| `simplify` | `number` | – | ค่าความคลาดเคลื่อนในการลดรายละเอียด ตั้งแต่ประมาณ `0.00005` (ละเอียด) ถึง `0.001` (หยาบ) |
| `combine` | `boolean` | – | รวมส่วนต่าง ๆ ของอ็อบเจ็กต์เป็นรูปทรงเดียว |
| `ignorefragment` | `boolean` | – | ข้ามชิ้นส่วนขนาดเล็ก |
| `ref` | `Ref<ObjectOverlayRef>` | – | `getObject()` และ `getOverlays()` |

รับ [props สไตล์ของรูปทรง](/th/docs/components/polygon#shape-props) ด้วย (`fillColor`, `lineColor`, `lineWidth`, `lineStyle`…)

## รหัสพื้นที่ [#area-ids]

รหัสพื้นที่ขึ้นต้นด้วย `A` ตามด้วยรหัสจังหวัด อำเภอ และตำบล โดยรหัสจังหวัดตรงกับรหัสที่ใช้ในระบบไปรษณีย์และสำมะโนของไทย

| รหัส | พื้นที่ |
| --- | --- |
| `A10000000` | กรุงเทพมหานคร |
| `A50000000` | เชียงใหม่ |
| `A83000000` | ภูเก็ต |
| `A50010000` | อำเภอเมืองเชียงใหม่ |

หากต้องการหารหัส ให้ค้นหาสถานที่ เช่น `useSearch().search("เชียงใหม่")` จะคืนผลลัพธ์พร้อม `id`
