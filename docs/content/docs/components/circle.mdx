## Props

| Prop | Type | Description |
| --- | --- | --- |
| `center` | `Location` | **Required.** Center of the circle. |
| `radius` | `number` | **Required.** Radius in degrees. One degree is about 111 km, so `0.01` is roughly 1.1 km. |

Circles also take the [shape props](/docs/components/polygon#shape-props).

<Callout>
  To size a circle in meters, divide by the length of one degree: `radius={meters / 111_320}`.
</Callout>

## Ref

| Method | Description |
| --- | --- |
| `getCircle()` | The underlying `sphere.Circle`. |
| `getCenter()` | Center of the circle. |

| `getBound`, `contains`, `intersects`, `within`, `distanceTo`, `rotate`, `shift`, `updateStyle`, `togglePopup`, `toGeoJSON` | As for [polygons](/docs/components/polygon#ref). |
