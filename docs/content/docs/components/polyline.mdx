## Props

| Prop | Type | Description |
| --- | --- | --- |
| `positions` | `Location[] \| GeoJSON` | **Required.** Points along the line (at least two). `null` entries break it into separate lines. A GeoJSON `LineString` or `MultiLineString` also works. |

Lines also take the [shape props](/docs/components/polygon#shape-props), such as `lineColor`, `lineWidth`, `lineStyle`, `label`, `popupContent` and the event callbacks.

## Line styles

`lineStyle` takes `"Solid"`, `"Dashed"`, `"Dot"` or your own dash pattern:

```tsx
<Polyline positions={path} lineStyle={[12, 4, 2, 4]} lineWidth={3} />
```

## Ref

| Method | Description |
| --- | --- |
| `getPolyline()` | The underlying `sphere.Polyline`. |
| `getLength(language?)` | Length in meters, or text such as `"15.5 km"` with a language. |
| `union(other)` | A new line joining this one and another (not added to the map). |
| `getBound()`, `getCentroid()`, `getPivot()` | Bounding box, center and label point. |
| `contains`, `intersects`, `within`, `distanceTo` | Spatial tests. See [Spatial analysis](/docs/examples/spatial-analysis). |
| `rotate`, `shift`, `updateStyle`, `togglePopup`, `toGeoJSON` | As for [polygons](/docs/components/polygon#ref). |
