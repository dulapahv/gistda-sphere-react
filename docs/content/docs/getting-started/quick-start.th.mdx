## ตัวอย่างพื้นฐาน [#minimal-example]

ครอบแอปด้วย `SphereProvider` แล้วใช้ `SphereMap` เพื่อแสดงแผนที่

<MapDemo height="400px" zoom={10} center={{ lon: 100.5018, lat: 13.7563 }}>
  <Marker position={{ lon: 100.5018, lat: 13.7563 }} title="กรุงเทพมหานคร" detail="เมืองหลวงของประเทศไทย" />
</MapDemo>

```tsx lineNumbers
import { SphereProvider, SphereMap, Marker } from 'gistda-sphere-react';

function App() {
  return (
    <SphereProvider apiKey="YOUR_API_KEY">
      <SphereMap
        center={{ lon: 100.5018, lat: 13.7563 }}
        zoom={10}
        style={{ width: '100%', height: '500px' }}
      >
        <Marker
          position={{ lon: 100.5018, lat: 13.7563 }}
          title="Bangkok"
          detail="Capital of Thailand"
        />
      </SphereMap>
    </SphereProvider>
  );
}
```

<Callout>
  หากใช้ App Router ของ Next.js ให้วางโค้ดนี้ใน Client Component โดยเพิ่ม `"use client";` ที่บรรทัดแรกของไฟล์
</Callout>

## แนวคิดสำคัญ [#key-concepts]

1. **`SphereProvider`** โหลดสคริปต์ของ Sphere ให้วางไว้เหนือทุกส่วนที่ใช้แผนที่
2. **`SphereMap`** คือตัวแผนที่ ต้องกำหนด**ความสูง**ให้แผนที่หรือคอนเทนเนอร์ของแผนที่ มิฉะนั้นจะสูง 0 px
3. **คอมโพเนนต์**อย่าง `Marker`, `Polygon`, `Layer` และ `Tag` วางไว้ใน `SphereMap` จะแสดงเมื่อ mount และหายไปเมื่อ unmount แผนที่จึงเปลี่ยนตาม state ของคุณ
4. **Hooks** อย่าง `useMapControls`, `useSearch`, `useRoute` และ `useUi` ใช้ได้ทุกที่ภายใต้ `SphereProvider` เช่น ในแถบด้านข้าง
5. **บริการเว็บ** เช่น การนำทาง การแปลงพิกัดเป็นที่อยู่ และข้อมูลการเกษตร เรียกใช้ผ่าน [`useSphereServices`](/th/docs/hooks/use-sphere-services) ได้แม้ไม่มีแผนที่

## การเพิ่มโอเวอร์เลย์ [#adding-overlays]

วางคอมโพเนนต์โอเวอร์เลย์เป็น children ของ `SphereMap`

<MapDemo height="400px" zoom={11} center={{ lon: 100.5018, lat: 13.7563 }}>
  <Marker position={{ lon: 100.5018, lat: 13.7563 }} title="กรุงเทพมหานคร" />
  <Polygon
    positions={[
      { lon: 100.41, lat: 13.78 },
      { lon: 100.47, lat: 13.78 },
      { lon: 100.44, lat: 13.73 },
    ]}
    fillColor="rgba(255, 0, 0, 0.3)"
    lineColor="red"
  />
  <Circle
    center={{ lon: 100.58, lat: 13.75 }}
    radius={0.03}
    fillColor="rgba(0, 100, 255, 0.3)"
    lineColor="blue"
  />
</MapDemo>

```tsx lineNumbers
<SphereMap style={{ width: '100%', height: '500px' }}>

  <Polygon
    positions={[
      { lon: 100.41, lat: 13.78 },
      { lon: 100.47, lat: 13.78 },
      { lon: 100.44, lat: 13.73 },
    ]}
    fillColor="rgba(255, 0, 0, 0.3)"
    lineColor="red"
  />
  <Circle

    radius={0.03}

  />
</SphereMap>
```
