## Install the package

```bash tab="npm"
npm install gistda-sphere-react
```

```bash tab="pnpm"
pnpm add gistda-sphere-react
```

```bash tab="yarn"
yarn add gistda-sphere-react
```

```bash tab="bun"
bun add gistda-sphere-react
```

The package has no other dependencies and ships its own TypeScript types. The Sphere map itself is loaded from GISTDA's servers when [`SphereProvider`](/docs/components/sphere-provider) mounts, so there's nothing else to install.

## Requirements

- **React 19 or later**, in any setup, such as Vite, Next.js or React Router. `react` and `react-dom` are peer dependencies.
- **A browser.** Maps render on the client. In the Next.js App Router, you can render the components from Server or Client Components, but hooks and event handlers need a Client Component (`"use client"`). See [Using it with Next.js](/docs/components/sphere-provider#using-it-with-nextjs). The [web services client](/docs/web-services#on-a-server) also runs on servers.
- **An API key** from GISTDA. See [Getting an API key](/docs/getting-started/api-key).
