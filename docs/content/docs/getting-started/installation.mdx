## Install the package

```bash tab="npm"
npm install gistda-sphere-react
```

```bash tab="pnpm"
pnpm add gistda-sphere-react
```

```bash tab="yarn"
yarn add gistda-sphere-react
```

```bash tab="bun"
bun add gistda-sphere-react
```

The package has no other dependencies and ships its own TypeScript types. The Sphere map itself is loaded from GISTDA's servers when [`SphereProvider`](/docs/components/sphere-provider) mounts, so there's nothing else to install.

## Requirements

- **React 19 or later.** `react` and `react-dom` are peer dependencies.
- **A browser.** Maps render on the client. With the Next.js App Router, use the components in Client Components (`"use client"`).
- **An API key** from GISTDA. See [Getting an API key](/docs/getting-started/api-key).
