---
title: Event hooks
description: Listen to any map event from a component, with typed arguments
---

Event hooks subscribe a component to map events and unsubscribe when it unmounts. They work inside `SphereMap` and anywhere else under `SphereProvider`, and the handler always sees your latest props and state.

<EventLogDemo />

## useMapEvent

```tsx
import { useMapEvent } from "gistda-sphere-react";

function ClickLogger() {
  useMapEvent("click", ({ lat, lon }) => {
    console.log(`Clicked at ${lat}, ${lon}`);
  });

  useMapEvent("overlayClick", (overlay, location) => {
    console.log("Overlay clicked at", location);
  });

  return null;
}
```

The handler's arguments are typed per event (see `SphereEventMap`). The event names and what they pass are listed on the [`SphereMap` events table](/docs/components/sphere-map#events), for example `click` ↔ `onClick`.

### Cancelling the context menu

Handlers can return `false` to cancel cancellable events. Use it with `beforeContextmenu` to add your own menu items or hide the menu:

```tsx
useMapEvent("beforeContextmenu", (menu) => {
  const item = document.createElement("button");
  item.textContent = "Add a stop here";
  item.onclick = () => addStop(menu.location);
  menu.add(item);
});
```

## Shortcuts

| Hook | Handler | Notes |
| --- | --- | --- |
| `useMapReady(handler)` | `(map) => void` | Runs once the map is ready, or right away if it already is. |
| `useMapClick(handler)` | `({ lat, lon, x, y }) => void` | Map clicks (not fired for clicks on overlays). |
| `useMapZoom(handler)` | `() => void` | Zoom changes. Read the level with `useMapControls().getZoom()`. |
| `useMapLocation(handler)` | `() => void` | Center changes. Read it with `useMapControls().getCenter()`. |
| `useOverlayClick(handler)` | `({ overlay, location }) => void` | Clicks on any overlay. |

```tsx
import { useMapControls, useMapReady, useMapZoom } from "gistda-sphere-react";

function ZoomIndicator() {
  const { getZoom } = useMapControls();
  const [zoom, setZoom] = useState<number | null>(null);

  useMapReady(() => setZoom(getZoom()));
  useMapZoom(() => setZoom(getZoom()));

  return <span>Zoom {zoom?.toFixed(1)}</span>;
}
```

<Callout>
  Events like `mousemove`, `zoom`, `location` and `repaint` fire many times per second while the map moves. Avoid heavy work in their handlers, or batch updates with `requestAnimationFrame`.
</Callout>

## Event props or event hooks?

Both receive the same events. Use [`SphereMap`'s `on…` props](/docs/components/sphere-map#events) when the map's owner handles the event, and event hooks when a child or a sidebar component cares about it.
