Event hooks ใช้ผูกคอมโพเนนต์เพื่อรับเหตุการณ์ของแผนที่ และยกเลิกอัตโนมัติเมื่อ unmount ใช้งานได้ทั้งภายใน `SphereMap` และทุกที่ภายใต้ `SphereProvider` โดย handler จะเข้าถึง props และ state ล่าสุดเสมอ

## useMapEvent

```tsx
import { useMapEvent } from "gistda-sphere-react";

function ClickLogger() {
  useMapEvent("click", ({ lat, lon }) => {
    console.log(`Clicked at ${lat}, ${lon}`);
  });

  useMapEvent("overlayClick", (overlay, location) => {
    console.log("Overlay clicked at", location);
  });

  return null;
}
```

อาร์กิวเมนต์ของ handler มี type ตามแต่ละเหตุการณ์ (ดู `SphereEventMap`) ดูชื่อเหตุการณ์และค่าที่ส่งมาได้ใน[ตารางเหตุการณ์ของ `SphereMap`](/th/docs/components/sphere-map#events) เช่น `click` ↔ `onClick`

### ยกเลิกเมนูคลิกขวา [#cancelling-the-context-menu]

handler สามารถคืนค่า `false` เพื่อยกเลิกเหตุการณ์ที่ยกเลิกได้ ใช้ร่วมกับ `beforeContextmenu` เพื่อเพิ่มรายการเมนูของคุณเองหรือซ่อนเมนู:

```tsx
useMapEvent("beforeContextmenu", (menu) => {
  const item = document.createElement("button");
  item.textContent = "Add a stop here";
  item.onclick = () => addStop(menu.location);
  menu.add(item);
});
```

## ทางลัด [#shortcuts]

| Hook | Handler | หมายเหตุ |
| --- | --- | --- |
| `useMapReady(handler)` | `(map) => void` | ทำงานเมื่อแผนที่พร้อม หรือทำงานทันทีหากพร้อมอยู่แล้ว |
| `useMapClick(handler)` | `({ lat, lon, x, y }) => void` | คลิกแผนที่ (ไม่รวมการคลิกโอเวอร์เลย์) |
| `useMapZoom(handler)` | `() => void` | ระดับซูมเปลี่ยน อ่านระดับซูมด้วย `useMapControls().getZoom()` |
| `useMapLocation(handler)` | `() => void` | จุดกึ่งกลางเปลี่ยน อ่านค่าด้วย `useMapControls().getCenter()` |
| `useOverlayClick(handler)` | `({ overlay, location }) => void` | คลิกโอเวอร์เลย์ใดก็ได้ |

```tsx
import { useMapControls, useMapReady, useMapZoom } from "gistda-sphere-react";

function ZoomIndicator() {
  const { getZoom } = useMapControls();
  const [zoom, setZoom] = useState<number | null>(null);

  useMapReady(() => setZoom(getZoom()));
  useMapZoom(() => setZoom(getZoom()));

  return <span>Zoom {zoom?.toFixed(1)}</span>;
}
```

<Callout>
  เหตุการณ์อย่าง `mousemove`, `zoom`, `location` และ `repaint` เกิดขึ้นหลายครั้งต่อวินาทีขณะแผนที่เคลื่อนที่ หลีกเลี่ยงงานหนักใน handler หรือรวบการอัปเดตด้วย `requestAnimationFrame`
</Callout>

## Event props หรือ event hooks [#event-props-or-event-hooks]

ทั้งสองแบบรับเหตุการณ์ชุดเดียวกัน ใช้ [props `on…` ของ `SphereMap`](/th/docs/components/sphere-map#events) เมื่อคอมโพเนนต์ที่ถือแผนที่เป็นผู้จัดการเหตุการณ์ และใช้ event hooks เมื่อคอมโพเนนต์ลูกหรือคอมโพเนนต์ในแถบด้านข้างต้องการใช้เหตุการณ์นั้น
