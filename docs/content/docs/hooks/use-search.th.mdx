`useSearch` ค้นหาข้อมูลสถานที่ของ Sphere ผ่านแผนที่ ใช้งานได้ทั้งภายใน `SphereMap` และทุกที่ภายใต้ `SphereProvider` หากต้องการค้นหาโดยไม่มีแผนที่ หรือบนเซิร์ฟเวอร์ ให้ใช้ [`useSphereServices`](/th/docs/hooks/use-sphere-services)

```tsx
import { type PoiResult, useSearch } from "gistda-sphere-react";
import { type FormEvent, useState } from "react";

function PlaceSearch() {
  const { search, isReady } = useSearch();
  const [keyword, setKeyword] = useState("");
  const [places, setPlaces] = useState<PoiResult[]>([]);

  async function handleSubmit(event: FormEvent<HTMLFormElement>) {
    event.preventDefault();
    const { data } = await search(keyword, { limit: 10 });
    setPlaces(data);
  }

  return (
    <form onSubmit={handleSubmit}>
      <input
        aria-label="Search places"
        onChange={(event) => setKeyword(event.target.value)}
        value={keyword}
      />
      <button disabled={!isReady} type="submit">
        Search
      </button>
      <ul>
        {places.map((place) => (
          <li key={place.id}>{place.name}</li>
        ))}
      </ul>
    </form>
  );
}
```

## ค่าที่คืนกลับ [#return-value]

| เมธอด | คืนค่า | คำอธิบาย |
| --- | --- | --- |
| `search(keyword, options?)` | `Promise<{ data: PoiResult[], meta }>` | สถานที่ที่ตรงกับคำค้นหา |
| `suggest(keyword, options?)` | `Promise<{ data: SuggestResult[], meta }>` | คำแนะนำสำหรับคำค้นหาที่พิมพ์ไม่ครบ |
| `nearPoi(location, options?)` | `Promise<PoiResult[]>` | สถานที่ใกล้ตำแหน่ง |
| `address(location, options?)` | `Promise<AddressResult \| null>` | ที่อยู่ ณ ตำแหน่ง หรือ `null` (ดูด้านล่าง) |
| `clear()` | | ล้างผลลัพธ์ที่แสดงใน [`SearchResults`](/th/docs/components/search-results) |
| `enablePopup(state)` / `isPopupEnabled()` | | ป๊อปอัปของหมุดผลลัพธ์ |
| `setPlaceholder(element, options?)` | | แสดงรายการผลลัพธ์ของ Sphere ใน element `<SearchResults>` ทำให้อัตโนมัติ |
| `setLanguage(language)` / `getLanguage()` | | ภาษาของผลลัพธ์ |
| `isReady` | `boolean` | เป็น `true` เมื่อแผนที่พร้อมใช้งาน |

`search`, `suggest` และ `nearPoi` จะ throw ข้อผิดพลาดพร้อมระบุชื่อบริการ หากบริการไม่คืนข้อมูลใด ๆ จึงควรครอบการเรียกด้วย `try`/`catch`

### ตัวเลือก [#options]

| ตัวเลือกของ `search` | คำอธิบาย |
| --- | --- |
| `limit`, `offset` | การแบ่งหน้า |
| `span` | รัศมีการค้นหาพร้อมหน่วย เช่น `"5km"`, `"500m"` |
| `tag` | เฉพาะสถานที่ที่มีแท็กนี้ เช่น `"โรงพยาบาล"` |
| `area` | เฉพาะสถานที่ในรหัสพื้นที่นี้ เช่น `"10"` สำหรับกรุงเทพฯ |
| `dataset` | ชุดข้อมูลที่จะค้นหา |

`suggest` รับ `limit`, `offset`, `area` และ `dataset` ส่วน `nearPoi` รับ `limit`, `span` (องศา) และ `zoom`

## ผลลัพธ์ [#results]

`PoiResult` แต่ละรายการมี `id`, `name`, `lat`, `lon` และหากมีข้อมูล จะมี `address`, `tel`, `url`, `tag` (รายการแท็ก), `distance` และอื่น ๆ ค่า `id` ยังใช้กับ [`<ObjectOverlay>`](/th/docs/components/object-overlay) เพื่อวาดขอบเขตของสถานที่ได้ด้วย

## ภาษา [#language]

ผลลัพธ์จะใช้ภาษาเดียวกับแผนที่ ซึ่งค่าเริ่มต้นคือภาษาไทย ดังนั้นแม้ค้นหาด้วยคำภาษาอังกฤษก็อาจได้ชื่อสถานที่เป็นภาษาไทย ให้กำหนด `language` ที่ [`SphereProvider`](/th/docs/components/sphere-provider#language) หรือ `SphereMap` เพื่อให้ได้ผลลัพธ์ภาษาอังกฤษ หรือเรียก `setLanguage` เพื่อเปลี่ยนเฉพาะภาษาของการค้นหา

## คำแนะนำขณะพิมพ์ [#autocomplete]

[`useSuggest`](/th/docs/hooks/use-suggest) ให้คำแนะนำขณะผู้ใช้พิมพ์ โดยจะรอจนผู้ใช้หยุดพิมพ์ และไม่สนใจผลลัพธ์ของคำค้นหาที่เก่ากว่า:

```tsx
import { useSuggest } from "gistda-sphere-react";
import { useState } from "react";

function SearchBox() {
  const [keyword, setKeyword] = useState("");
  const { suggestions } = useSuggest(keyword, { limit: 5 });

  return (
    <>
      <input
        aria-label="Search places"
        onChange={(event) => setKeyword(event.target.value)}
        value={keyword}
      />
      <ul>
        {suggestions.map((suggestion, index) => (
          <li key={`${suggestion.name}:${index}`}>{suggestion.name}</li>
        ))}
      </ul>
    </>
  );
}
```

หากเรียก `suggest` เอง ให้รอจนผู้ใช้หยุดพิมพ์และทิ้งผลลัพธ์ของคำค้นหาที่เก่ากว่า มิฉะนั้นผลลัพธ์ที่มาช้าอาจแทนที่คำแนะนำที่ใหม่กว่า

## ที่อยู่ [#addresses]

```tsx
import { useSearch } from "gistda-sphere-react";

const { address } = useSearch();

async function logAddress() {
  const result = await address({ lon: 100.5018, lat: 13.7563 });
  if (result) {
    console.log(result.province, result.district, result.subdistrict, result.road);
  }
}
```

<Callout type="warn">
  `address` จะคืนค่า `null` เมื่อไม่มีที่อยู่ ณ ตำแหน่งนั้น และเมื่อ API key ไม่ได้เปิดบริการที่อยู่ ส่วนการค้นหา คำแนะนำ และสถานที่ใกล้เคียงใช้บริการอื่น จึงอาจใช้งานได้แม้ที่อยู่ใช้งานไม่ได้
</Callout>
