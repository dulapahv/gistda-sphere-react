## useMarkers

```tsx
import { Marker, SphereMap, useMarkers } from "gistda-sphere-react";

function Stores() {
  const { items, add, remove } = useMarkers();

  return (
    <>
      <button
        onClick={() => add({ position: { lon: 100.5, lat: 13.75 }, title: "New store" })}
      >
        Add store
      </button>
      <SphereMap>
        {items.map((marker) => (
          <Marker
            key={marker.id}
            position={marker.position}
            title={marker.title}
            onClick={() => remove(marker.id)}
          />
        ))}
      </SphereMap>
    </>
  );
}
```

## usePolygons, usePolylines และ useCircles [#usepolygons-usepolylines-and-usecircles]

ทำงานแบบเดียวกันสำหรับข้อมูลของ `Polygon` (`positions`), `Polyline` (`positions`) และ `Circle` (`center`, `radius`)

## useOverlays

ทั้งสี่คอลเลกชันในครั้งเดียว

```tsx
import { useOverlays } from "gistda-sphere-react";

const { markers, polygons, polylines, circles, clearAll } = useOverlays();
```

## ค่าที่คืนกลับ [#return-value]

hook คอลเลกชันแต่ละตัวคืนค่า

| Property | ชนิด | คำอธิบาย |
| --- | --- | --- |
| `items` | `T[]` | รายการโอเวอร์เลย์ แต่ละรายการมี `id` |
| `add(data)` | `string` | เพิ่มโอเวอร์เลย์ และคืน ID ใหม่ |
| `update(id, changes)` | | รวมการเปลี่ยนแปลงเข้ากับโอเวอร์เลย์ |
| `remove(id)` | | ลบโอเวอร์เลย์ |
| `clear()` | | ลบโอเวอร์เลย์ชนิดนี้ทั้งหมด |
| `get(id)` | `T \| undefined` | หาโอเวอร์เลย์จาก ID |

อ็อบเจกต์ข้อมูลรับ props ชุดเดียวกับคอมโพเนนต์ (`title`, `fillColor`, `draggable`…) จึง spread ค่าใส่คอมโพเนนต์ได้โดยตรง: `<Polygon key={p.id} {...p} />`
