---
title: useRoute
description: Plan routes with several stops and travel modes, with status, totals and turn-by-turn directions
---

`useRoute` plans a route on the map and keeps its result in React state: status, error, totals and ready-to-show turn-by-turn steps. It works inside `SphereMap` and anywhere else under `SphereProvider`.

<RouteDemo />

```tsx
import { useRoute } from "gistda-sphere-react";

function Directions() {
  const route = useRoute();
  const { status, error, summary, steps } = route;

  const plan = () => {
    route.clear();
    route.addDestination({ lon: 100.5018, lat: 13.7563 }); // Bangkok
    route.addDestination({ lon: 98.9853, lat: 18.7883 });  // Chiang Mai
    route.search();
  };

  return (
    <div>
      <button onClick={plan} disabled={status === "calculating"}>Plan route</button>
      {error && <p>{error.message}</p>}
      {summary && (
        <p>{summary.distanceText} · {summary.intervalText}</p>
      )}
      <ol>
        {steps.map((step, index) => (
          <li key={index}>
            {step.instruction} ({step.distanceText})
          </li>
        ))}
      </ol>
    </div>
  );
}
```

The route and its stop markers are drawn on the map by Sphere. Users can drag the stops, and click one to remove it.

## Result state

| Property | Type | Description |
| --- | --- | --- |
| `status` | `"idle" \| "calculating" \| "complete" \| "error"` | Where the calculation is. |
| `isCalculating` | `boolean` | Shortcut for `status === "calculating"`. |
| `summary` | `RouteSummary \| null` | Totals: `distance` (m), `distanceText`, `interval` (s), `intervalText`. |
| `steps` | `RouteStep[]` | Turn-by-turn steps. |
| `routes` | `RouteResult[]` | The raw legs from Sphere, one per pair of consecutive stops. |
| `error` | `RouteErrorInfo \| null` | Why the last calculation failed. |
| `isReady` | `boolean` | `true` once the map is ready. |

## Turn-by-turn directions

Each step is ready to display:

| `RouteStep` field | Example | Description |
| --- | --- | --- |
| `instruction` | `"Turn right to Sathon Nuea Rd"` | Readable instruction in the route language. |
| `distanceText` | `"640 m"` | Formatted step distance. |
| `intervalText` | `"1 min"` | Formatted step time (empty in Fly mode). |
| `turn` | `1` | Turn code; compare with [`ROUTE_TURN`](#turn-codes) to pick an icon. |
| `name` | `"Sathon Nuea Rd"` | Road name. |
| `distance`, `interval` | `640`, `60` | Raw meters and seconds. |
| `legIndex` | `0` | Which leg (pair of stops) the step belongs to. |

Instructions follow the route language, which you can change with `setLanguage("en")`. For Sphere's own styled panel instead, add [`<RouteGuide>`](/docs/components/route-guide).

Road names come from the routing service in the language used for the calculation, so after changing the language (with `setLanguage` or `SphereMap`'s `language` prop), call `search()` again to update them.

### Turn codes

```tsx
import { ROUTE_TURN } from "gistda-sphere-react";

const icons = {
  [ROUTE_TURN.TurnLeft]: "↰",
  [ROUTE_TURN.TurnRight]: "↱",
  [ROUTE_TURN.Straight]: "↑",
  [ROUTE_TURN.UTurn]: "↶",
  [ROUTE_TURN.Arrive]: "⚑",
};
```

`ROUTE_TURN` has `TurnLeft`, `TurnRight`, `SlightLeft`, `SlightRight`, `HeadToward`, `Straight`, `EnterExpressway`, `UTurn`, `Arrive` and `Ferry`. `getTurnInstruction(turn, roadName, language)` builds an instruction yourself, e.g. for data from the [routing web service](/docs/web-services/routing).

## Errors

| `error.code` | Meaning |
| --- | --- |
| a number | Sphere's status code, e.g. `410` when there's no data for the selected time. |
| `"timeout"` | The routing service didn't answer within `timeout` (20 s by default). This usually means your API key doesn't have the routing service enabled. |
| `"exception"` | Sphere threw while planning the route. `error.message` has the details. |

## Options

```tsx
const route = useRoute({
  timeout: 15_000,
  onRouteComplete: (routes) => console.log("Done", routes),
  onError: (error) => toast(error.message),
});
```

| Option | Type | Description |
| --- | --- | --- |
| `timeout` | `number` | Milliseconds before reporting a `"timeout"` error. Default `20000`; `0` turns it off. |
| `onRouteComplete` | `(routes) => void` | A route finished calculating. |
| `onRouteError` | `(status) => void` | Sphere reported a routing error code. |
| `onError` | `(error: RouteErrorInfo) => void` | Any failure, including timeouts. |

## Stops

| Method | Description |
| --- | --- |
| `addDestination(location, mode?)` | Add a stop (a location or a `sphere.Marker`), optionally with its own travel mode for the next leg. |
| `insertDestination(index, location, mode?)` | Insert a stop at a position. |
| `removeDestination(marker)` / `removeDestinationAt(index)` | Remove a stop. |
| `listDestinations()` / `size()` | The stop markers / how many there are. |
| `reverse()` | Reverse the order of the stops. |
| `clearDestinations()` | Remove all stops. |
| `clearPath()` | Remove the drawn route, keeping the stops. |
| `clear()` | Remove stops and route, and reset the result state. |
| `search()` | Calculate the route. |

## Travel modes and options

| Method | Description |
| --- | --- |
| `setMode(mode)` / `getMode()` | `"Traffic"` (fastest, avoiding traffic jams; the default), `"Cost"` (fastest by road, without traffic data), `"Distance"` (shortest) or `"Fly"` (straight lines). |
| `setModeAt(index, mode)` / `getModeAt(index)` | Mode of the leg starting at a stop. |
| `enableRouteType(type, state)` / `isRouteTypeEnabled(type)` | Allow or avoid `"Road"`, `"Ferry"`, `"Tollway"` or `"All"`. |
| `setRestrict("Bike", state)` / `isRestrictEnabled("Bike")` | Avoid roads closed to motorcycles. |
| `setLabel(label)` / `getLabel()` | Label on the route: `"Distance"`, `"Time"` or `"Hide"`. |
| `setLineStyle(part, style)` / `getLineStyle(part)` | Style of `"Road"`, `"Ferry"`, `"Destination"` or `"Focus"` lines. |
| `setAuto(state)` / `getAuto()` | Recalculate automatically when stops change. |
| `enableContextMenu()` | Add a "Direction to here" item to the right-click menu, which adds a stop there. Also turns on `auto`. |
| `setLanguage(language)` / `getLanguage()` | Language of instructions and labels. |

```tsx
route.setMode("Distance");
route.enableRouteType("Tollway", false); // avoid tollways
route.setRestrict("Bike", true);         // motorcycle-friendly roads
route.setLineStyle("Road", { lineColor: "#2563eb", lineWidth: 6 });
```

<Callout>
  Fly mode draws straight lines and works without the routing service. Sphere can't label straight-line legs (it throws), so `useRoute` hides route labels while Fly is used and restores your label setting afterwards.
</Callout>

## Data and export

| Method | Description |
| --- | --- |
| `getSteps()` | Steps of the current route, read on demand. |
| `getDistance(format?)` / `getInterval(format?)` | Totals in meters / seconds, or formatted text. |
| `getGuide(format?)` | Raw legs, or Sphere's formatted guide as a `DocumentFragment`. |
| `exportRouteLine(style?)` | The whole route as one `sphere.Polyline` (not added to the map). Call `.toJSON()` for GeoJSON. |
| `setPlaceholder(element)` | Render Sphere's guide panel into an element. |

<Callout type="warn">
  Routing needs the routing service enabled for your API key. Without it, Sphere gives no error of its own; `useRoute` reports a `"timeout"` error instead of waiting forever.
</Callout>
