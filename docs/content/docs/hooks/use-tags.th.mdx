`useTags` จัดการชั้นข้อมูลแท็ก POI แบบ imperative ใช้งานได้ทั้งภายใน `SphereMap` และทุกที่ภายใต้ `SphereProvider` หากต้องการให้แท็กเปลี่ยนตาม state คอมโพเนนต์ [`<Tag>`](/th/docs/components/tag) มักใช้ง่ายกว่า

```tsx
import { useTags } from "gistda-sphere-react";

function FoodToggle() {
  const { add, remove, list } = useTags();
  const shown = list().includes("อาหารไทย");
  return (
    <button onClick={() => (shown ? remove("อาหารไทย") : add("อาหารไทย"))}>
      {shown ? "Hide" : "Show"} Thai restaurants
    </button>
  );
}
```

## ค่าที่คืนกลับ [#return-value]

| เมธอด | คำอธิบาย |
| --- | --- |
| `add(tag, options?)` | เพิ่มชั้นข้อมูลแท็กโดยเก็บแท็กอื่นไว้ `tag` คือชื่อแท็ก (หลายชื่อคั่นด้วย `\|`) หรือฟังก์ชันที่คืนค่า POI ของแต่ละไทล์ |
| `set(tag, options?)` | แทนที่ชั้นข้อมูลแท็กทั้งหมดด้วยแท็กนี้ |
| `remove(tag)` | ลบชั้นข้อมูลแท็ก ชื่อที่คั่นด้วย `\|` จะถูกลบทีละชื่อ |
| `clear()` | ลบชั้นข้อมูลแท็กทั้งหมด |
| `list()` / `size()` | ชื่อ / จำนวนชั้นข้อมูลแท็กบนแผนที่ |
| `enablePopup(state)` / `isPopupEnabled()` | ป๊อปอัปเมื่อคลิก POI |
| `setLanguage(language)` / `getLanguage()` | ภาษาของชื่อ POI |
| `isReady` | เป็น `true` เมื่อแผนที่พร้อมใช้งาน |

`options` เหมือนกับ [props ของ `<Tag>`](/th/docs/components/tag#props) ได้แก่ `visibleRange`, `label`, `icon`, `area`, `type`, `source` เป็นต้น

## POI ของคุณเองรายไทล์ [#your-own-pois-per-tile]

ส่งฟังก์ชันแทนชื่อแท็กเพื่อให้ข้อมูล POI เอง Sphere จะเรียกฟังก์ชันนี้สำหรับทุกไทล์ของแผนที่

```tsx
add((tile) =>
  myStores
    .filter((store) => isInTile(store, tile))
    .map((store) => ({ lat: store.lat, lon: store.lon, name: store.name }))
);
```

## ชื่อแท็ก [#tag-names]

แท็กระบุด้วยชื่อภาษาไทย เช่น `"ธนาคาร/สถาบันการเงิน"` (ธนาคาร) หรือ `"โรงพยาบาล"` (โรงพยาบาล) [`useTagCategories`](/th/docs/hooks/use-tag-categories) โหลดรายการทั้งหมดพร้อมชื่อภาษาอังกฤษ ส่วน `TAG_CATEGORIES` เป็นรายการในตัวขนาดเล็กที่ไม่ต้องส่งคำขอ
