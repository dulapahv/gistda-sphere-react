`useMap` ใช้เข้าถึง Sphere API โดยตรงสำหรับส่วนที่ไลบรารีนี้ไม่ได้หุ้มไว้ ใช้งานได้ทุกที่ภายใต้ `SphereProvider`

```tsx
import { useMap } from "gistda-sphere-react";

function ZoomLabel() {
  const { map, isReady } = useMap();
  if (!isReady || !map) return null;
  return <span>Zoom: {map.zoom()}</span>;
}
```

## ค่าที่คืนกลับ [#return-value]

| Property | ชนิด | คำอธิบาย |
| --- | --- | --- |
| `map` | `SphereMapInstance \| null` | อินสแตนซ์ของ `sphere.Map` |
| `sphere` | `SphereNamespace \| null` | namespace `sphere` แบบ global (คลาส enum และ `Util`) |
| `isReady` | `boolean` | เป็น `true` เมื่อแผนที่พร้อมใช้งาน |

## แผนที่ MapLibre [#the-maplibre-map]

Sphere แสดงผลด้วย [MapLibre GL JS](https://maplibre.org/maplibre-gl-js/docs/) โดย `map.Renderer` คือแผนที่ MapLibre จึงใช้ฟีเจอร์และปลั๊กอินของ MapLibre ได้ด้วย

```tsx
import { useMap } from "gistda-sphere-react";
import { useEffect } from "react";

const { map } = useMap();

useEffect(() => {
  const renderer = map?.Renderer;
  if (!renderer) return;
  const onMove = () => console.log(renderer.getBearing());
  renderer.on("move", onMove);
  return () => {
    renderer.off("move", onMove);
  };
}, [map]);
```

ดูตัวอย่างฉบับเต็มที่[การใช้ปลั๊กอินของ MapLibre](/th/docs/examples/maplibre-plugins)

## ภายในแผนที่ [#inside-a-map]

ภายใน `SphereMap` นั้น `useMapContext()` จะคืนค่า `{ map, isReady }` ของแผนที่นั้นโดยเฉพาะ ซึ่งสำคัญเมื่อ provider เดียวมีหลายแผนที่

<Callout>
  แนะนำให้ใช้คอมโพเนนต์และ hooks ที่มี type กำกับหากมีให้ใช้ เพราะจะคืนทรัพยากรให้อัตโนมัติเมื่อ unmount ซึ่งการเรียกใช้ API โดยตรงไม่ได้จัดการให้
</Callout>
