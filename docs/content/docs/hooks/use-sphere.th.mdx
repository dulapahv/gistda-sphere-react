---
title: useSphere
description: สถานะการโหลดของ Sphere API และ namespace ของ sphere โดยไม่ต้องมีแผนที่
---

`useSphere` รายงานว่าสคริปต์ Sphere โหลดเสร็จหรือยัง และให้ namespace `sphere` แบบ global โดยไม่ต้องมีแผนที่

```tsx
import { useSphere } from "gistda-sphere-react";

function ApiStatus() {
  const { isLoaded, error } = useSphere();
  if (error) return <p>Couldn't load the map API: {error.message}</p>;
  return <p>{isLoaded ? "Map API ready" : "Loading…"}</p>;
}
```

## ค่าที่คืนกลับ [#return-value]

| Property | ชนิด | คำอธิบาย |
| --- | --- | --- |
| `sphere` | `SphereNamespace \| null` | namespace `sphere` แบบ global เมื่อโหลดเสร็จ |
| `isLoaded` | `boolean` | เป็น `true` เมื่อโหลดสคริปต์เสร็จ |
| `error` | `Error \| null` | สาเหตุที่โหลดสคริปต์ไม่สำเร็จ (ถ้ามี) |
| `apiKey` | `string` | key ที่ส่งให้ `SphereProvider` |

ใช้ namespace นี้เพื่อเข้าถึงคลาสและ enum ของ Sphere เช่น `new sphere.Polygon(...)` หรือ `sphere.Util.formatDistance(1500, "en")` สำหรับการจัดรูปแบบและการแปลงข้อมูลที่มี type กำกับผลลัพธ์ ดู [`useSphereUtils`](/th/docs/hooks/use-sphere-utils)
