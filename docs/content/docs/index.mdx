A React wrapper for the [GISTDA Sphere Map API](https://sphere.gistda.or.th/). Build interactive maps of Thailand with full TypeScript support.

## Features

- **The whole Sphere API**: every map class, event and option, mapped on the [API coverage](/docs/api-coverage) page.
- **Declarative components** for maps, markers, popups, shapes, GeoJSON, layers, POI tags, live data and controls. They clean up after themselves and update in place.
- **React everywhere**: React content in marker icons, popups and map controls.
- **Routing that just works**: route status, totals and readable turn-by-turn steps as React state.
- **Search, places and POIs**: search with autocomplete, nearby places, addresses, area outlines and over 250 POI tags in 20 categories.
- **Data and analysis**: GeoJSON, KML, GPX and WKT; heatmaps, clusters and 3D; measurements and polygon operations.
- **Web services**: a typed client for routing, geocoding, elevation, static maps, agriculture, disasters and population, in the browser or on a server.
- **TypeScript first**: typed props, refs, results and events.

## Quick install

```bash
npm install gistda-sphere-react
```
