## การสร้างไคลเอนต์ [#getting-a-client]

ใน React ภายใต้ `SphereProvider` ให้ใช้ `useSphereServices` ซึ่งใช้ key ของ provider และใช้ `language` ของ provider เป็นภาษาของผลลัพธ์ หากไม่ได้ส่ง `locale`

```tsx
import { useSphereServices } from "gistda-sphere-react";
import { useState } from "react";

function PlaceName() {
  const services = useSphereServices({ locale: "en" });
  const [name, setName] = useState("");

  const find = async () => {
    const { data } = await services.search.search("central world");
    setName(data[0]?.name ?? "Not found");
  };

  return (
    <button onClick={find} type="button">
      {name || "Find Central World"}
    </button>
  );
}
```

ที่อื่น ๆ รวมถึง Node.js 18 ขึ้นไปและ serverless functions ให้สร้างไคลเอนต์ด้วย key ของคุณ โดย import จาก `gistda-sphere-react/services` ซึ่งไม่รวม React และโค้ดแผนที่ (entry หลักก็ export ไว้เช่นกัน)

```ts
import { createSphereServices } from "gistda-sphere-react/services";

const services = createSphereServices({
  apiKey: process.env.SPHERE_API_KEY!,
  locale: "en",
});
```

| ตัวเลือก | ชนิด | ค่าเริ่มต้น | คำอธิบาย |
| --- | --- | --- | --- |
| `apiKey` | `string` | **จำเป็น** (เฉพาะ `createSphereServices`) | API key ที่เปิดบริการที่จะเรียกใช้แล้ว |
| `locale` | `"th" \| "en"` | `"th"` | ภาษาเริ่มต้นของผลลัพธ์ เมธอดส่วนใหญ่รับ `locale` ได้ด้วย |
| `timeout` | `number` | `15000` | เวลารอ (มิลลิวินาที) ก่อนคำขอล้มเหลว ส่ง `0` เพื่อปิด |
| `method` | `"auto" \| "get" \| "post"` | `"auto"` | `"auto"` ส่งแบบ GET และเปลี่ยนเป็น POST แบบฟอร์มเมื่อ URL ยาวเกินไป (รูปหลายเหลี่ยมขนาดใหญ่ เมทริกซ์ระยะทาง) |
| `baseUrl` | `string` | `https://api.sphere.gistda.or.th/services` | URL ของบริการ เช่น proxy ของคุณ |
| `fetch` | `typeof fetch` | `fetch` แบบ global | ฟังก์ชัน fetch ของคุณเอง |
| `referer` | `string` | – | URL ของหน้าเว็บในโดเมนที่ key อนุญาต ส่งไปเป็น header `Referer` จำเป็นบนเซิร์ฟเวอร์เมื่อ key จำกัดโดเมน ดู[บนเซิร์ฟเวอร์](#on-a-server) |
| `headers` | `Record<string, string>` | – | header เพิ่มเติมที่ส่งไปกับทุกคำขอ เช่น สำหรับ proxy ของคุณ |

## ตำแหน่งและพื้นที่ [#locations-and-areas]

เมธอดที่ใช้ดึงข้อมูลตามตำแหน่งจะรับค่า `{ lon, lat }` และหลายเมธอดยังรับ GeoJSON geometry เช่น รูปหลายเหลี่ยม เพื่อดึงข้อมูลทั้งพื้นที่แทนได้:

```ts
await services.agri.rice({ lon: 100.5, lat: 14.2 });
await services.agri.rice({
  type: "Polygon",
  coordinates: [[[100.4, 14.1], [100.6, 14.1], [100.6, 14.3], [100.4, 14.1]]],
});
```

## ข้อผิดพลาด [#errors]

ทุกเมธอดจะ throw `SphereServiceError` เมื่อการเรียกล้มเหลว

```ts
import { SphereServiceError } from "gistda-sphere-react";

try {
  await services.route.route({
    from: { lon: 100.5018, lat: 13.7563 },
    to: { lon: 100.5604, lat: 13.7466 },
  });
} catch (error) {
  if (error instanceof SphereServiceError) {
    console.log(error.code, error.service, error.status, error.message);
  }
}
```

| `code` | ความหมาย |
| --- | --- |
| `"key"` | API key ไม่ได้รับอนุญาตให้ใช้บริการนี้ ให้เปิดบริการให้กับ key (Sphere ตอบกลับด้วย HTTP 200 และข้อความแจ้งข้อผิดพลาด ซึ่งไคลเอนต์ตรวจจับให้) บนเซิร์ฟเวอร์ key ที่จำกัดโดเมนต้องกำหนด [`referer`](#on-a-server) ด้วย |
| `"http"` | บริการตอบกลับด้วย HTTP error ดู `status` และ `body` |
| `"timeout"` | ไม่มีการตอบกลับภายใน `timeout` |
| `"aborted"` | คุณยกเลิกคำขอด้วย `signal` |
| `"network"` | ส่งคำขอไม่ได้ เช่น ออฟไลน์หรือถูก CORS บล็อก |
| `"parse"` | ข้อมูลที่ตอบกลับไม่ใช่ JSON |

## ยกเลิกคำขอ [#cancelling-requests]

ทุกเมธอดรับ `signal` และ `timeout`

```ts
const controller = new AbortController();
const pending = services.search.suggest("วัดพ", { signal: controller.signal, timeout: 5000 });
controller.abort(); // pending rejects with code "aborted"
```

## บนเซิร์ฟเวอร์ [#on-a-server]

ไคลเอนต์ทำงานได้ทุกที่ที่มี `fetch` เช่น Node.js 18 ขึ้นไป serverless functions รวมถึง route handlers และ Server Components ของ Next.js ตัวอย่าง route handler นี้ค้นหาด้วย key ที่มีเฉพาะฝั่งเซิร์ฟเวอร์:

```ts title="app/api/places/route.ts"
import { createSphereServices } from "gistda-sphere-react/services";

const services = createSphereServices({
  apiKey: process.env.SPHERE_API_KEY!,
  locale: "en",
  // A page on a domain your key allows
  referer: "https://www.example.com/",
});

export async function GET(request: Request) {
  const keyword = new URL(request.url).searchParams.get("q") ?? "";
  const { data } = await services.search.search(keyword);
  return Response.json(data);
}
```

Sphere ตรวจสอบว่าคำขอมาจากเว็บไซต์ใดผ่าน header `Referer` ซึ่งเบราว์เซอร์จะส่งให้ แต่เซิร์ฟเวอร์ไม่ส่ง ดังนั้น key ที่จำกัดโดเมนจะใช้งานบนเซิร์ฟเวอร์ไม่ได้และได้ข้อผิดพลาด code `"key"` ให้กำหนด `referer` เป็นหน้าเว็บในโดเมนที่ key อนุญาต หรือใช้ key ที่ไม่จำกัดโดเมน

<Callout type="warn">
  ต้องเปิดบริการแต่ละตัวให้กับ API key ใน Sphere console และอย่านำ key ของเซิร์ฟเวอร์ไปไว้ในโค้ดฝั่งไคลเอนต์ ใน Next.js อย่าตั้งชื่อตัวแปรของ key เหล่านี้ให้ขึ้นต้นด้วย `NEXT_PUBLIC_`
</Callout>
