## หลักการทำงาน [#how-it-works]

- ตัวจับเวลาจะเลื่อนรถทุกวินาที ในแอปของคุณให้ใช้ตำแหน่งจากเซิร์ฟเวอร์แทน เช่น ผ่าน WebSocket หรือการ polling
- `animate` ของ [`<Marker>`](/th/docs/components/marker#moving-markers) จะเลื่อนหมุดไปยังตำแหน่งใหม่ โดยใช้เวลาน้อยกว่าช่วงเวลาการอัปเดตเล็กน้อย (900 มิลลิวินาทีสำหรับการอัปเดตทุกวินาที) การเคลื่อนที่จึงดูต่อเนื่อง และการเลื่อนแต่ละครั้งจะจบก่อนครั้งถัดไปเริ่ม
- `rotate` หมุนไอคอนตามทิศทางการเดินทาง และการเปลี่ยนค่านี้ไม่ทำให้หมุดถูกสร้างใหม่
- เส้นทางย้อนหลังของรถแต่ละคันเป็น [`<Polyline>`](/th/docs/components/polyline) ของตำแหน่งล่าสุด
- การติดตามรถจะเรียก `setCenter` จาก [`useMapControls`](/th/docs/hooks/use-map-controls) หลังการอัปเดตแต่ละครั้ง

<Callout>
  `animate` ใช้ได้กับไอคอน HTML และ React ควรให้ prop อื่นของหมุด เช่น `title` และ `icon` คงที่ขณะเคลื่อนที่ เพราะการเปลี่ยนค่าเหล่านั้นจะทำให้หมุดถูกสร้างใหม่
</Callout>
