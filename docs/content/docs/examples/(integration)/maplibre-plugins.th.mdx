เบื้องหลังแผนที่ Sphere ทุกตัวคือแผนที่ [MapLibre GL JS](https://maplibre.org/maplibre-gl-js/docs/) ซึ่งเข้าถึงได้ผ่าน `map.Renderer` จึงสามารถนำปลั๊กอินและ API ของ MapLibre มาใช้งานได้โดยตรง

## เข้าถึงแผนที่ MapLibre [#get-the-maplibre-map]

```tsx lineNumbers
import { useMap } from "gistda-sphere-react";
import { useEffect } from "react";

function Terrain() {
  const { map } = useMap();

  useEffect(() => {
    const renderer = map?.Renderer;
    if (!renderer) return;
    renderer.addSource("dem", { type: "raster-dem", url: "https://example.com/terrain.json", tileSize: 256 });
    renderer.setTerrain({ source: "dem", exaggeration: 1.5 });
    return () => {
      renderer.setTerrain(null);
      renderer.removeSource("dem");
    };
  }, [map]);

  return null;
}
```

หากใช้ ref: `mapRef.current?.getMap()?.Renderer`

## ตัวควบคุมของ MapLibre [#a-maplibre-control]

```tsx
import maplibregl from "maplibre-gl";
import { useUi } from "gistda-sphere-react";
import { useEffect } from "react";

const ui = useUi();
useEffect(() => {
  if (!ui.isReady) return;
  const control = new maplibregl.NavigationControl({ visualizePitch: true });
  ui.addControl(control);
  return () => ui.removeControl(control);
}, [ui]);
```

หากตัวควบคุมสร้างด้วย React ใช้ [`<MapControl>`](/th/docs/components/map-control) จะง่ายกว่า

## เงาของอาคาร [#building-shadows]

[ตัวอย่างเงาของอาคาร](https://sphere.gistda.or.th/docs/js/building-shadow)ของ GISTDA ใช้ปลั๊กอิน [ShadeMap](https://shademap.app) จากภายนอก ซึ่งต้องมี API key ของตัวเอง และ key ของ Mapbox สำหรับข้อมูลภูมิประเทศและอาคาร เมื่อใช้กับไลบรารีนี้

```tsx lineNumbers
import { SphereMap, useMap } from "gistda-sphere-react";
import { useEffect } from "react";

function Shadows({ date }: { date: Date }) {
  const { map } = useMap();

  useEffect(() => {
    const renderer = map?.Renderer;
    if (!renderer) return;
    const shade = new (window as any).ShadeMap({
      apiKey: SHADEMAP_KEY,
      date,
      color: "#01112f",
      opacity: 0.7,
      // terrainSource and getFeatures as in the ShadeMap documentation
    });
    shade.addTo(renderer);
    return () => shade.remove();
  }, [map, date]);

  return null;
}

<SphereMap options={{ maxPitch: 45 }}>
  <Shadows date={new Date()} />
</SphereMap>
```

<Callout type="warn">
  อย่าลืมลบสิ่งที่คุณเพิ่มเข้าไปใน renderer เมื่อคอมโพเนนต์ unmount (ชั้นข้อมูล, source, ตัวควบคุม และ event listener) เนื่องจากไลบรารีจะคืนทรัพยากรเฉพาะสิ่งที่สร้างผ่านคอมโพเนนต์และ hook ของไลบรารีเท่านั้น
</Callout>
