## ล็อกไว้จนกว่าจะคลิก [#lock-until-clicked]

`useUi().lockMap()` วางปุ่มทับแผนที่ไว้ แผนที่จะตอบสนองหลังผู้ใช้คลิกเท่านั้น และล็อกใหม่ได้

```tsx lineNumbers
import { SphereMap, useUi } from "gistda-sphere-react";
import { useEffect } from "react";

function ScrollLock() {
  const ui = useUi();
  useEffect(() => {
    if (!ui.isReady) return;
    const lock = ui.lockMap();
    return () => lock?.remove();
  }, [ui]);
  return null;
}

<SphereMap style={{ height: 400 }}>
  <ScrollLock />
</SphereMap>
```

ข้อความบนปุ่มเปลี่ยนตามภาษาของแผนที่ กำหนดเองได้ด้วย `lockMap({ unlockLabel, lockLabel })`

## ปิดเฉพาะการซูมด้วยล้อเมาส์ [#turn-off-wheel-zoom-only]

```tsx
import { useUi } from "gistda-sphere-react";
import { useEffect } from "react";

const ui = useUi();
useEffect(() => {
  if (ui.isReady) ui.setMouseEnabled({ wheel: false });
}, [ui]);
```

ผู้ใช้ยังลากแผนที่ได้ และซูมได้ด้วยแถบซูมหรือการดับเบิลคลิก

## แผนที่ภาพนิ่ง [#a-static-map]

```tsx
import { SphereMap } from "gistda-sphere-react";

<SphereMap input={false} controls={{ DPad: false, Zoombar: false, Geolocation: false, LayerSelector: false }} />
```
