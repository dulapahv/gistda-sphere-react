ระบบค้นหาสาขาจะแสดงสาขาจำนวนมากบนแผนที่และแสดงรายการสาขาที่ใกล้ที่สุด ตัวอย่างนี้จัดกลุ่มสาขาตัวอย่าง 120 แห่ง แสดงรายการสาขาในพื้นที่ที่มองเห็นโดยเรียงตามระยะห่างจากจุดกึ่งกลางของแผนที่ และเลื่อนไปยังตำแหน่งของผู้ใช้เมื่อกดปุ่ม:

## หลักการทำงาน [#how-it-works]

- [`<MarkerCluster>`](/th/docs/components/marker-cluster) แสดงสาขาทั้งหมด แผนที่จึงยังทำงานได้เร็ว และทุกสาขายังเป็นหมุด React ของตัวเอง
- [`useMapView`](/th/docs/hooks/event-hooks#usemapview) ให้ขอบเขตที่มองเห็นและจุดกึ่งกลางทุกครั้งที่แผนที่หยุดเคลื่อนที่ รายการจะเก็บเฉพาะสาขาที่อยู่ในขอบเขตนั้นและเรียงตามระยะทาง จึงเปลี่ยนตามแผนที่เมื่อผู้ใช้เลื่อนหรือซูม
- การคลิกสาขาในรายการหรือบนแผนที่จะแสดง [`<Popup>`](/th/docs/components/popup) ที่ควบคุมด้วย state และการคลิกในรายการยังเลื่อนแผนที่ไปยังสาขานั้นด้วย `goTo`
- ปุ่ม "Stores near me" ขอตำแหน่งจากเบราว์เซอร์ด้วย `navigator.geolocation` แล้วเลื่อนแผนที่ไปที่นั่น จากนั้นรายการจะอัปเดตเอง

<Callout>
  เบราว์เซอร์จะแชร์ตำแหน่งเฉพาะในหน้าที่ปลอดภัย (`https://` หรือ `localhost`) และหลังจากผู้ใช้อนุญาตเท่านั้น จึงควรจัดการกรณีที่เกิดข้อผิดพลาดเสมอ
</Callout>

เมื่อใช้ข้อมูลจริง ให้โหลดสาขาจาก API ของคุณและเก็บอาร์เรย์ไว้ให้คงที่ (ด้วย `useMemo` หรือ state) เพราะ `MarkerCluster` จะจัดกลุ่มจุดใหม่ทุกครั้งที่ `items` เป็นอาร์เรย์ใหม่
