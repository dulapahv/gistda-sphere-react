## รูปแบบอื่น [#variations]

- **หลายจุดแวะ**: เรียก `addDestination` สำหรับทุกจุด จุดที่ต่อกันแต่ละคู่คือหนึ่งช่วงใน `route.routes`
- **ให้ผู้ใช้วางแผนบนแผนที่**: `route.enableContextMenu()` เพิ่มเมนู "เดินทางมาจุดนี้" ในเมนูคลิกขวา ผู้ใช้ลากจุดแวะได้ และเส้นทางจะอัปเดตเอง
- **แผงคำแนะนำของ Sphere**: แสดง [`<RouteGuide>`](/th/docs/components/route-guide) ข้างแผนที่
- **ไม่ใช้แผนที่เลย**: [บริการเว็บการนำทาง](/th/docs/web-services/routing)คืนข้อมูลชุดเดียวกันในรูปแบบ GeoJSON

<Callout>
  หากไม่มีอะไรเกิดขึ้นและได้รับข้อผิดพลาด `"timeout"` หลังผ่านไป 20 วินาที แสดงว่า API key ของคุณยังไม่ได้เปิดบริการนำทาง ส่วนโหมด "เส้นตรง" ใช้งานได้โดยไม่ต้องเปิดบริการนี้
</Callout>
