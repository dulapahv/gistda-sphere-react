Each `<Tag>` adds its layer when it mounts and removes it when it unmounts, so the map always matches `activeTags`. To manage tags imperatively instead, use [`useTags`](/docs/hooks/use-tags):

```tsx
import { useTags } from "gistda-sphere-react";

const { add, remove, clear } = useTags();
add("โรงพยาบาล");
add("เอทีเอ็ม");
remove("โรงพยาบาล");
```
