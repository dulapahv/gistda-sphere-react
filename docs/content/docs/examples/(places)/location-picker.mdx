## How it works

- The pin is an element on top of the map with `pointer-events: none`, so dragging still moves the map.
- [`onViewChange`](/docs/components/sphere-map#syncing-the-view) reports the center once the map stops moving, so there's one lookup per move instead of one per frame.
- `address()` from [`useSearch`](/docs/hooks/use-search#addresses) turns the center into an address. An answer for an older center is ignored, so a slow lookup never replaces a newer one.

<Callout type="warn">
  Addresses need the address service enabled for your API key. Without it, `address()` resolves `null`, and the example tells users so.
</Callout>

To let users search first, add [`useSuggest`](/docs/hooks/use-suggest) and move the map to the chosen place with `goTo`.
