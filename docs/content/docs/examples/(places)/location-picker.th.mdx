## หลักการทำงาน [#how-it-works]

- หมุดเป็น element ที่วางทับแผนที่และกำหนด `pointer-events: none` การลากจึงยังเลื่อนแผนที่ได้ตามปกติ
- [`onViewChange`](/th/docs/components/sphere-map#syncing-the-view) รายงานจุดกึ่งกลางเมื่อแผนที่หยุดเคลื่อนที่ จึงค้นหาที่อยู่เพียงครั้งเดียวต่อการเลื่อนหนึ่งครั้ง แทนที่จะค้นหาทุกเฟรม
- `address()` จาก [`useSearch`](/th/docs/hooks/use-search#addresses) แปลงจุดกึ่งกลางเป็นที่อยู่ โดยผลลัพธ์ของจุดกึ่งกลางเดิมจะถูกละเว้น การค้นหาที่ช้าจึงไม่แทนที่ผลลัพธ์ที่ใหม่กว่า

<Callout type="warn">
  การค้นหาที่อยู่ต้องเปิดบริการที่อยู่ให้กับ API key หากไม่ได้เปิด `address()` จะคืนค่า `null` และตัวอย่างจะแจ้งให้ผู้ใช้ทราบ
</Callout>

หากต้องการให้ผู้ใช้ค้นหาก่อน ให้เพิ่ม [`useSuggest`](/th/docs/hooks/use-suggest) แล้วเลื่อนแผนที่ไปยังสถานที่ที่เลือกด้วย `goTo`
