## ไอเดียเพิ่มเติม [#ideas]

- แสดงขอบเขตของผลลัพธ์ที่เป็นพื้นที่ (จังหวัดหรืออำเภอ) ด้วย [`<ObjectOverlay id={place.id} fitBounds />`](/th/docs/components/object-overlay)
- ให้ผลลัพธ์เน้นบริเวณที่อยู่บนจอ: `search(keyword, { span: "5km" })` รอบจุดกึ่งกลางแผนที่ หรือใช้[บริการเว็บสำหรับค้นหา](/th/docs/web-services/search-and-places#search)กับ `near`
- หากต้องการรายการผลลัพธ์สำเร็จรูปของ Sphere ให้ใช้ [`<SearchResults>`](/th/docs/components/search-results) แทนการสร้างเอง
