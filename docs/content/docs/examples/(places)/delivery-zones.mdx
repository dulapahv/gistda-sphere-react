## How it works

- Each zone is a [`<Polygon>`](/docs/components/polygon). A callback ref keeps every zone's ref in a `Map` keyed by name, and removes it when the zone unmounts.
- `contains(location)` on a polygon ref tells whether a point lies inside the zone. [Spatial analysis](/docs/examples/spatial-analysis) covers the other tests.
- A click on a zone is an overlay click, so the map handles both `onClick` and `onOverlayClick`.
- `fillColor` is a live prop, so highlighting the matching zone updates the polygon without re-creating it.

To check an address that users type, find it with [`useSearch`](/docs/hooks/use-search) or [`useSuggest`](/docs/hooks/use-suggest), then pass its `{ lon, lat }` to the same check.
