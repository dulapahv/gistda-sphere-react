## ใช้ useMarkers แทน [#with-usemarkers-instead]

ตัวอย่างนี้เก็บหมุดไว้ใน state ของคอมโพเนนต์ หากต้องการเก็บไว้ใน hook แทน และรับการคลิกจากคอมโพเนนต์ลูกของแผนที่ ให้ใช้ [`useMarkers`](/th/docs/hooks/overlay-hooks) และ [`useMapEvent`](/th/docs/hooks/event-hooks):

```tsx lineNumbers
import { SphereProvider, SphereMap, Marker, useMarkers, useMapEvent } from 'gistda-sphere-react';

function MarkerPlacer() {
  const { items: markers, add, clear } = useMarkers();

  useMapEvent('click', (location) => {
    add({ position: location });
  });

  return (
    <>
      <button onClick={clear}>Clear</button>
      {markers.map((m) => (
        <Marker key={m.id} position={m.position} />
      ))}
    </>
  );
}

function App() {
  return (
    <SphereProvider apiKey="YOUR_API_KEY">
      <SphereMap center={{ lon: 100.5, lat: 13.75 }} zoom={10} style={{ height: '500px' }}>
        <MarkerPlacer />
      </SphereMap>
    </SphereProvider>
  );
}
```
