## การดำเนินการกับรูปหลายเหลี่ยม [#polygon-operations]

```tsx lineNumbers
import { GeoJson, Polygon, type PolygonRef, type GeoJSON, type Location } from "gistda-sphere-react";
import { useRef, useState } from "react";

function Overlap({ zoneA, zoneB }: { zoneA: Location[]; zoneB: Location[] }) {
  const a = useRef<PolygonRef>(null);
  const b = useRef<PolygonRef>(null);
  const [result, setResult] = useState<GeoJSON | null>(null);

  const intersect = () => {
    const other = b.current?.getPolygon();
    const overlap = other ? a.current?.intersection(other) : null;
    setResult(overlap ? overlap.toJSON() : null);
  };

  return (
    <>
      <Polygon ref={a} positions={zoneA} fillColor="rgba(59,130,246,.25)" />
      <Polygon ref={b} positions={zoneB} fillColor="rgba(245,158,11,.25)" />
      {result && <GeoJson data={result} style={{ fillColor: "rgba(239,68,68,.4)", lineStyle: "Dashed" }} />}
    </>
  );
}
```

| เมธอด | ผลลัพธ์ |
| --- | --- |
| `a.union(b)` | พื้นที่ทั้งหมดที่รูปใดรูปหนึ่งครอบคลุม ใช้รวมเส้นได้ด้วย |
| `a.intersection(b)` | เฉพาะส่วนที่ซ้อนทับกัน |
| `a.difference(b)` | `a` ที่ตัดส่วนของ `b` ออก |
| `a.split(b)` | `a` ที่ถูกแบ่งเป็นชิ้นตามขอบของ `b` (เป็นอาร์เรย์) |

ผลลัพธ์เป็นโอเวอร์เลย์ของ Sphere ที่ยังไม่อยู่บนแผนที่ แสดงได้ด้วย `<GeoJson data={result.toJSON()} />` หรือเพิ่มผ่านอ็อบเจกต์แผนที่ของ Sphere โดยตรง

## การทดสอบ [#tests]

```tsx
zoneRef.current?.contains({ lon: 100.5, lat: 13.75 }); // is the point inside?
zoneRef.current?.intersects(otherOverlay);              // do they touch or overlap?
zoneRef.current?.within(otherOverlay);                  // is the zone fully inside the other?
zoneRef.current?.distanceTo(storeMarker, "en");          // "2.4 km"
```

`contains`, `intersects` และ `distanceTo` รับตำแหน่ง `{ lon, lat }` หรือโอเวอร์เลย์อื่น ส่วน `within` รับโอเวอร์เลย์ ดึงโอเวอร์เลย์จาก ref ได้ด้วย `markerRef.current?.getMarker()`, `polygonRef.current?.getPolygon()` เป็นต้น

## การวัดขนาด [#measurements]

```tsx
import { useSphereUtils } from "gistda-sphere-react";

polygonRef.current?.getArea();     // square meters
polygonRef.current?.getArea("th"); // "120 ตร.กม."
lineRef.current?.getLength("en");  // "15.5 km"
circleRef.current?.getRadius("en"); // "5.48 km"

const { formatThaiArea } = useSphereUtils();
formatThaiArea(polygonRef.current?.getArea() as number, "th"); // "74,995 ไร่ 3 งาน 76 ตร.ว."
```

การวัดคำนวณบนผิวโลก (geodesic) จึงแม่นยำแม้อยู่ไกลจากเส้นศูนย์สูตร
