## แผนที่ความร้อน [#heatmap]

ส่งสไตล์ MapLibre ที่มี source แบบ GeoJSON และชั้นข้อมูลชนิด `heatmap`:

```tsx lineNumbers
const HEATMAP = {
  sources: {
    quakes: { type: "geojson", data: "https://maplibre.org/maplibre-gl-js/docs/assets/earthquakes.geojson" },
  },
  layers: [
    {
      id: "quakes-heat",
      type: "heatmap",
      source: "quakes",
      paint: {
        "heatmap-weight": ["interpolate", ["linear"], ["get", "mag"], 0, 0, 6, 1],
        "heatmap-radius": ["interpolate", ["linear"], ["zoom"], 0, 2, 9, 20],
      },
    },
  ],
};

<SphereMap zoom={3}>
  <Layer style={HEATMAP} />
</SphereMap>
```

## การจัดกลุ่มจุด [#clustering]

source แบบ GeoJSON จัดกลุ่มจุดที่อยู่ใกล้กันได้ด้วย `cluster: true` และกำหนดสไตล์ของกลุ่มตาม `point_count`

```tsx lineNumbers
const CLUSTERS = {
  sources: {
    stores: { type: "geojson", data: storesGeoJson, cluster: true, clusterRadius: 50 },
  },
  layers: [
    {
      id: "store-clusters",
      type: "circle",
      source: "stores",
      filter: ["has", "point_count"],
      paint: {
        "circle-color": ["step", ["get", "point_count"], "#51bbd6", 100, "#f1f075", 750, "#f28cb1"],
        "circle-radius": ["step", ["get", "point_count"], 14, 100, 22, 750, 32],
      },
    },
    {
      id: "store-points",
      type: "circle",
      source: "stores",
      filter: ["!", ["has", "point_count"]],
      paint: { "circle-color": "#11b4da", "circle-radius": 5 },
    },
  ],
};

<Layer style={CLUSTERS} />
```

กำหนด ID ของ source และชั้นข้อมูลในแต่ละสไตล์ไม่ให้ซ้ำกัน เพื่อป้องกันไม่ให้ `<Layer>` สองตัวชนกัน

## อาคาร 3 มิติ (I3S และ 3D Tiles) [#3d-buildings-i3s-and-3d-tiles]

```tsx lineNumbers
const { goTo } = useMapControls();

<Layer
  name="sf-buildings"
  type="I3S"
  url="https://tiles.arcgis.com/tiles/z2tnIkrLQ2BRzr6P/arcgis/rest/services/SanFrancisco_Bldgs/SceneServer/layers/0"
  onTilesetLoad={(tileset) => {
    const [lon, lat] = tileset.cartographicCenter ?? [];
    goTo({ center: { lon, lat }, zoom: (tileset.zoom ?? 13) + 3, pitch: 60 });
  }}
/>
```

ใช้ `type="Tiles3D"` กับ URL ของ `tileset.json` สำหรับ OGC 3D Tiles ซึ่งรวมถึงโมเดลจากภาพถ่าย (photogrammetry) และพอยต์คลาวด์ (`pointSize`) tileset ขนาดใหญ่ใช้เวลาหลายวินาทีก่อน `onTilesetLoad` จะทำงาน

## โมเดล glTF [#gltf-models]

`ScenegraphLayer` ของ deck.gl ใช้วางโมเดล 3 มิติ ให้สร้างเพียงครั้งเดียวโดยครอบด้วย `deck.MapboxLayer`

```tsx lineNumbers
function Model() {
  const layer = useMemo(() => {
    const { deck } = window as unknown as { deck: any };
    return new deck.MapboxLayer({
      id: "box",
      type: deck.ScenegraphLayer,
      data: [{ position: [100.5018, 13.7563, 0] }],
      getPosition: (item) => item.position,
      getScale: [100, 100, 100],
      scenegraph: "https://raw.githubusercontent.com/KhronosGroup/glTF-Sample-Models/master/2.0/Box/glTF-Binary/Box.glb",
    });
  }, []);
  return <Layer layer={layer} />;
}
```

เอียงแผนที่ (`pitch`) เพื่อดูวัตถุ 3 มิติจากด้านข้าง ใส่ `options={{ maxPitch: 85 }}` ให้ `SphereMap` เพื่อให้เอียงได้มากขึ้น
