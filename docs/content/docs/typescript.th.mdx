ไลบรารีนี้เขียนด้วย TypeScript และ export ทุก type จากแพ็กเกจหลัก

```tsx
import type { Location, PoiResult, PolygonRef, RouteStep } from "gistda-sphere-react";
```

## Type ที่ใช้บ่อย [#common-types]

| Type | รูปแบบ |
| --- | --- |
| `Location` | `{ lon: number; lat: number }` |
| `Point` | `{ x: number; y: number }` (พิกเซล) |
| `Size` | `{ width: number; height: number }` |
| `Range` | `{ min: number; max: number }` |
| `Bound` | `{ minLon; minLat; maxLon; maxLat }` |
| `Icon` | `{ url?; urlHD?; html?; offset?; size? }` |
| `GeoJSON`, `GeoJSONFeature`, `GeoJSONGeometry`… | อ็อบเจกต์ GeoJSON (RFC 7946) |

## Props และ ref [#props-and-refs]

คอมโพเนนต์แต่ละตัว export type ของ props และ ref เช่น `SphereMapProps`, `SphereMapRef`, `MarkerProps`, `MarkerRef`, `PolygonProps` และ `PolygonRef` ใช้ type ของ props เมื่อสร้างคอมโพเนนต์ที่ครอบคอมโพเนนต์ของไลบรารี

```tsx
import { Marker, type MarkerProps } from "gistda-sphere-react";

function StoreMarker({ open, ...props }: MarkerProps & { open: boolean }) {
  return <Marker {...props} icon={{ url: open ? "/open.png" : "/closed.png" }} />;
}
```

## อ็อบเจกต์ของ Sphere [#sphere-objects]

อ็อบเจกต์ของ Sphere เองก็มี type: `SphereMapInstance` (`sphere.Map`), `SphereMarker`, `SpherePolygon`, `SpherePolyline`, `SphereCircle`, `SphereDot`, `SphereRectangle`, `SpherePopup`, `SphereOverlay`, `SphereLayer` และ `SphereNamespace` (ตัวแปร `sphere` ส่วนกลาง) ส่วน `MapLibreMap` ครอบคลุมสมาชิกที่ใช้บ่อยของ `map.Renderer`

เมธอดของ Sphere ใช้ได้ทั้งอ่านและกำหนดค่า เมื่อเรียกโดยไม่ส่งอาร์กิวเมนต์จะคืนค่าพร้อม type ของค่านั้น และเมื่อส่งอาร์กิวเมนต์จะคืนอ็อบเจกต์เดิมเพื่อให้เรียกต่อกันได้:

```tsx
import type { SphereMapInstance } from "gistda-sphere-react";

function zoomIn(map: SphereMapInstance) {
  const zoom = map.zoom(); // number
  map.zoom(zoom + 1); // returns the map, for chaining
}
```

เมื่อ import แพ็กเกจแล้ว `window.sphere` และ `window.deck` (deck.gl ที่มากับ Sphere ซึ่งกำหนด type แบบหลวม ๆ ไว้เป็น `DeckNamespace`) จะถูกประกาศเป็น global type ให้ทั้งโปรเจกต์ โดยทั้งคู่มี type เป็น optional เนื่องจากจะมีค่าเมื่อสคริปต์ของ Sphere โหลดเสร็จแล้วเท่านั้น ดู[ชั้นข้อมูล deck.gl](/th/docs/components/layer#deckgl-and-raw-maplibre-layers)
