This page maps the [Sphere API reference](https://api.sphere.gistda.or.th/map/doc.html) and the [web services](https://api.sphere.gistda.or.th/services/api) to this library. Anything not wrapped is still reachable through [`useMap()`](/docs/hooks/use-map), which gives you the raw `sphere.Map`.

## Map

| Sphere | Library |
| --- | --- |
| `new sphere.Map(options)` | [`<SphereMap>`](/docs/components/sphere-map) |
| `MapOptions.layer`, `zoom`, `zoomRange`, `location`, `ui`, `input`, `lastView`, `language` | `baseLayer`, `zoom`, `zoomRange`, `center`, `ui`, `input`, `lastView`, `language` props |
| MapLibre map options | `options` prop |
| `map.zoom()` | `zoom` prop, `setZoom`, `getZoom`, `zoomIn`, `zoomOut`, `onZoom` |
| `map.zoomRange()` | `zoomRange` prop, `setZoomRange`, `getZoomRange`, `onZoomRange` |
| `map.location()` | `center` prop, `setCenter`, `getCenter`, `onLocation` |
| `map.bound()` | `setBound`, `getBound` |
| `map.move()` | `panBy` |
| `map.goTo()` | `goTo` |
| `map.rotate()`, `map.pitch()` | `rotate`/`pitch` props, `setRotate`/`getRotate`, `setPitch`/`getPitch`, `onRotate`/`onPitch` |
| `map.language()` | `language` prop, `setLanguage`, `getLanguage` |

## Beyond the Sphere API

The library also adds things the Sphere API doesn't have:

- Declarative components that clean up after themselves, with props that update the map in place.
- React content as marker icons, popups and map controls.
- Route results as React state: `status`, `summary`, turn-by-turn `steps` with readable instructions, and a timeout for keys without routing.
- `onError` for objects that never load, and errors with codes for every web service.
- Spatial analysis and measurements on every shape ref.
- A typed web services client that works on servers too.
- Workarounds for Sphere quirks: `input={false}` disabling interaction, labels in Fly mode, removing `"a|b"` tags, plain-text areas, and more.
