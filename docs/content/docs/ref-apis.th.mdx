---

คอมโพเนนต์ทุกตัวที่วาดบนแผนที่รับ `ref` ได้ ซึ่งให้เมธอดแบบ imperative และอ็อบเจกต์ของ Sphere ที่อยู่เบื้องหลัง

```tsx
import { useRef } from "react";
import { Polygon, SphereMap, type PolygonRef, type SphereMapRef } from "gistda-sphere-react";

function Example() {
  const mapRef = useRef<SphereMapRef>(null);
  const zoneRef = useRef<PolygonRef>(null);

  const zoomToZone = () => {
    const bound = zoneRef.current?.getBound();
    if (bound) mapRef.current?.setBound(bound, { padding: 40 });
  };

  return (
    <SphereMap ref={mapRef}>
      <Polygon ref={zoneRef} positions={zone} onClick={zoomToZone} />
    </SphereMap>
  );
}
```

## ชนิดของ ref [#ref-types]

| คอมโพเนนต์ | ชนิดของ ref | เมธอดเด่น |
| --- | --- | --- |
| `SphereMap` | `SphereMapRef` | [มุมมอง ชั้นข้อมูล ตัวกรองสี ภาษา](/th/docs/components/sphere-map#ref), `getMap()` |
| `Marker` | `MarkerRef` | [`setPosition`, `setRotation`, `togglePopup`, `getElement`](/th/docs/components/marker#ref) |
| `Popup` | `PopupRef` | [`setPosition`, `setTitle`, `setDetail`](/th/docs/components/popup#ref) |
| `Polygon` | `PolygonRef` | [`getArea`, `union`, `intersection`, `difference`, `split`](/th/docs/components/polygon#ref) |
| `Polyline` | `PolylineRef` | [`getLength`, `union`](/th/docs/components/polyline#ref) |
| `Circle` | `CircleRef` | [`getArea`, `getRadius`, `getCenter`](/th/docs/components/circle#ref) |
| `Rectangle` | `RectangleRef` | [เหมือนรูปหลายเหลี่ยม](/th/docs/components/rectangle#ref) |
| `Dot` | `DotRef` | [`getPosition`, `setPosition`](/th/docs/components/dot#ref) |
| `GeoJson` | `GeoJsonRef` | `getOverlays()`, `getBound()` |
| `ObjectOverlay` | `ObjectOverlayRef` | `getObject()`, `getOverlays()` |
| `MenuBar` | `MenuBarRef` | `getMenuBar()`, `select(index)` |

## เมธอดที่รูปทรงทุกแบบมีร่วมกัน [#shared-shape-methods]

หมุด จุด และรูปทรงต่าง ๆ มีเมธอดเชิงพื้นที่เหล่านี้ร่วมกัน (`OverlaySpatialMethods`)

| เมธอด | คำอธิบาย |
| --- | --- |
| `contains(target)` | ตำแหน่งหรือโอเวอร์เลย์นั้นอยู่ภายในโอเวอร์เลย์นี้หรือไม่ |
| `intersects(target)` | สัมผัสหรือซ้อนทับกันหรือไม่ |
| `within(overlay)` | โอเวอร์เลย์นี้อยู่ภายในโอเวอร์เลย์อื่นหรือไม่ |
| `distanceTo(target, language?)` | ระยะทางที่สั้นที่สุดเป็นเมตร หรือเป็นข้อความเมื่อระบุภาษา |
| `shift({ lon, lat })` | เลื่อนตามระยะที่กำหนดเป็นองศา |
| `toGeoJSON()` | โอเวอร์เลย์ในรูปแบบ GeoJSON feature |

รูปทรงยังมี `getBound`, `getCentroid`, `getPivot`, `rotate`, `updateStyle` และ `togglePopup` (`GeometryRefMethods`) ดูตัวอย่างได้ที่[การวิเคราะห์เชิงพื้นที่](/th/docs/examples/spatial-analysis)

<Callout>
  เรียกเมธอดของ ref ได้ทุกเมื่อ โดยจะคืนค่า `null` หรือ `false` ระหว่างที่โอเวอร์เลย์ยังไม่ถูกสร้าง ให้เรียกจาก event handler หรือ effect ไม่ใช่ระหว่าง render
</Callout>
